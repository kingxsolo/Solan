# التحقق من مُرمِّز AArch64 (SOLAN_JIT=2)

حلقتا تحقق مستقلتان تعملان على ويندوز x86 مباشرة (لا تحتاجان جهاز ARM):

## 1) التحقق التفكيكي — armgen.c + armverify.py

يبني 146 تعليمة عبر `arm64.inc` الحقيقية (برولوج/حراسات/FP/مساعدون/إبيلوج/إزاحات حدّية)
ويفككها بـcapstone مع تأكيدات على الترميزات الحرجة.

```
gcc -I <جذر المشروع> armgen.c -o armgen.exe -O1
armgen.exe                 → ينتج armgen.bin
python armverify.py        → تفكيك كامل + تأكيدات (يتطلب: pip install capstone)
```

## 2) التحقق التنفيذي الدلالي — armt.c + armrun.py

يبني 59 نواة اختبارية ذاتية الاحتواء عبر `arm64.inc` الحقيقية (كل نواة = سيناريو
من jit.inc: فوريات، حساب صحيح، sdiv/msub بالسالب، إزاحات، شروط صحيحة، FP
حساب/تقريب/تحويل، خريطة شروط FP بكل حالات NaN، ذاكرة بإزاحات حدّية ومفهرسة،
حلقة بترقيع b.cond، بركة LDR literal، إطار كامل برولوج+مساعد+إبيلوج مع فحص
حفظ السجلات المحفوظة) ثم ينفّذها على محاكي Unicorn ARM64 ويتحقق من النتائج
العددية — يصطاد أخطاء الدلالة التي لا يراها التفكيك.

```
gcc -I <جذر المشروع> armt.c -o armt.exe -O1
armt.exe                   → ينتج armt.bin + armt.lst
python armrun.py           → تنفيذ وتحقق (يتطلب: pip install unicorn)
```

## ما صطادته هذه الحلقات سابقاً

- إنقاذ x30 (LR) المفقود في البرولوج — blr المساعدين كان يسحقه → حلقة لانهائية
- حقل hw=1 المفقود في MOVK داخل jx_ldi32 — الثوابت الكبيرة تُخزَّن مشوّهة
- خريطة شروط FP بعد fcmp: أعلام unordered على AArch64 هي N=0 Z=0 C=0 V=1
  (مختلفة عن x86) — فالمطابقة الصحيحة AE→GE وB→LT

أعد تشغيلهما بعد أي تعديل على arm64.inc أو ترقيعات jit.inc الخاصة بـARM.
