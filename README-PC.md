# سولان لويندوز — النسخة الأصلية الكاملة (PC Edition)

نسخة ويندوز **أصلية 100%** من لغة سولان العربية: ملف `solan.exe` واحد، مترجم بـ C، مربوط ثابتاً (static)، بلا أي اعتماديات خارجية — لا MSYS2، لا WSL، لا بيئة لينكس، لا بايثون، لا Node.

## لماذا هذه النسخة سريعة؟

| التقنية | الأثر |
| --- | --- |
| مترجم GCC 16 مع `-O3` و **LTO** (تحسين عبر الوحدات كلها) | كود آلة مُحسَّن بأقصى درجة |
| استهداف `x86-64-v2` (SSE4.2 + POPCNT) | تعليمات حديثة مع توافق واسع (كل المعالجات منذ 2009) |
| ربط **ثابت** (static linking) | لا DLL خارجية → إقلاع فوري، وملف واحد قابل للنقل |
| **JIT أصلي x64** مدمج | الحلقات الساخنة تُترجم إلى كود آلة أثناء التشغيل |
| كومة ذاكرة منخفضة التجزؤ (LFH) على ويندوز | تخصيص ذاكرة أسرع للبرامج كثيفة الكائنات |
| Manifest مع `activeCodePage=UTF-8` و`longPathAware` | مسارات عربية طويلة تعمل بلا مشاكل |

النتيجة: تشغيل أسرع من بايثون CPython وNode.js في معظم المهام الحسابية الصرفة بفضل الـ JIT، مع إقلاع أسرع من كليهما (لا وقت إقلاع مفسّر).

### أرقام مقاسة فعلياً (نوفمبر 2026، نفس الجهاز)

## التثبيت

### الطريقة الأولى: المُثبِّت (موصى بها)
1. شغّل `dist\Solan-1.1.0-Setup-x64.exe`
2. اختر ما تريد: أيقونة سطح المكتب، إضافة إلى PATH، ربط ملفات `.سو`
3. انتهى — افتح أي طرفية واكتب `solan`

### الطريقة الثانية: الملف التنفيذي وحده
انسخ `dist\solan.exe` إلى أي مجلد في `PATH` (مثل `C:\Windows` لا — الأفضل `%LOCALAPPDATA%\Programs\solan` وأضفه إلى PATH).

## البناء من المصدر (على ويندوز نفسه)

```powershell
# مرة واحدة: تنزيل مترجم محمول (بلا تثبيت على النظام)
powershell -ExecutionPolicy Bypass -File pc\get-compiler.ps1

# البناء + إنشاء المُثبِّت
powershell -ExecutionPolicy Bypass -File pc\build-pc.ps1 -Installer
```

خيارات إضافية:
- `-V3` : استهداف x86-64-v3 (AVX2) لأجهزة 2013+ — في القياسات الفعلية كان الفرق طفيفاً على المهام الحسابية (متساوٍ تقريباً)، ويبقى الخيار مفيداً لمهام SIMD المستقبلية.
- `-NoStrip` : الاحتفاظ بالرموز للتنقيح (debug).

## كل ما يعمل في نسخة لينكس يعمل هنا

- تشغيل الملفات: `solan ملف.سو` — الامتدادات `.سو` `.an` `.solan`
- كود مباشر: `solan -e 'اطبع("هلا")'`
- الوضع التفاعلي (REPL): `solan`
- فحص الصياغة: `solan --check ملف.سو`
- التنسيق: `solan fmt ملف.سو -w`
- تلوين: `solan --لون ملف.سو` / `--html`
- التتبع والتصحيح: `--تتبع` / `--تصحيح`
- خادم اللغة للمحررات: `solan lsp`
- أوامر الحزم كلها: `init` `add` `install` `update` `publish`...
- المكتبات المدمجة: `نظام` `جيسون` `شبكة` `سوكت` `حلقة` `رياضيات` `ملفات` `قاعدة`...
- المكتبة القياسية المكتوبة بسولان مدمجة داخل الملف التنفيذي.

### إضافات النسخة الشخصية (فوق نسخة لينكس)

**شبكة.جلب — خيارات إضافية:**

| الخيار | الوظيفة |
| --- | --- |
| `بصمة` | انتحال بصمة TLS لعميل حقيقي: `"chrome"` أو `"android"` أو `"firefox"` أو `"curl"` (ClientHello كامل: التشفيرات، الامتدادات، ترتيبها) |
| `بروكسي` | توجيه الاتصال عبر `"socks5://مضيف:منفذ"` أو `"http://مضيف:منفذ"` (CONNECT) |
| `رؤوس_فقط` | طلب HEAD فقط (`صح`) — يعيد الرؤوس بلا جسم |
| `تشفيرات` | قائمة تشفيرات TLS صريحة |

- ALPN يتفاوض `h2` فقط (HTTP/2) — متوافق مع بصمات المتصفحات.
- حزمة شهادات CA احتياطية مدمجة: إن لم توجد شهادات النظام تُستخدم حزمة مدمجة حتى يعمل HTTPS فوراً.

**نظام.نفذ — الصيغة الموسعة:**

```
خل ر = نظام.نفذ("برنامج", {دخل: "نص الإدخال", مهلة: 5, مجلد: "C:\\عمل"})
// ر = {رمز: 0, ناتج: "...", خطأ: "...", انتهى_الوقت: غلط}
```

`مهلة` بالثواني؛ عند تجاوزها يُنهى البرنامج وتكون `رمز = -2` و`انتهى_الوقت = صح`.

**تشفير — إضافات:** `sha512` · `hmac_sha1` · `base64_رابط` · عائلة X25519 (`x25519_سر` / `x25519_عام` / `x25519_مشترك`) · عائلة Ed25519 (`ed25519_سر` / `ed25519_عام` / `ed25519_وقّع` / `ed25519_تحقق`) — تنفيذ خالص من الصفر وفق RFC 7748/8032، مُتحقق منه بمتجهات RFC الرسمية في `pc/اختبار_منحنى.سو` (29 اختباراً على x64 وx86). التفاصيل في README الرئيسي تحت «تشفير».

### فروق ويندوز المعروفة
- `https`/`wss` تحتاج `libssl-3-x64.dll` (حمّلها من `winget install ShiningLight.OpenSSL.Light` وضع DLL بجوار `solan.exe` أو في مجلد التثبيت). باقي كل شيء يعمل بلا أي متطلبات.
- لا `fork` — لذلك `عملية()` تعمل عبر نسخ العملية (متوافقة سلوكياً).
- SQLite مدمجة داخل الملف التنفيذي في هذه النسخة إن كانت متوفرة وقت البناء، وإلا تُحمَّل من النظام.

## بنية مجلد النسخة الشخصية

```
pc/
  build-pc.ps1      سكربت البناء الكامل (تجميع + فحص + مُثبِّت)
  get-compiler.ps1  تنزيل مترجم محمول تلقائياً
  installer.iss     سكربت المُثبِّت (Inno Setup) بواجهة عربية
  ArabicPC.isl      ترجمة عربية لواجهة المُثبِّت
  solan.rc          موارد ويندوز: معلومات الإصدار + الأيقونة
  solan.manifest    بيان UTF-8 والمسارات الطويلة
  solan.ico         أيقونة سولان
dist/
  solan.exe                    الناتج النهائي (ملف واحد مستقل)
  Solan-1.1.0-Setup-x64.exe    المُثبِّت
```

## تعديلات المصدر الخاصة بالنسخة الشخصية

كلها في `src/platform/platform.inc` و`src/runtime/main.inc` وموسومة بتعليقات عربية:
1. **طبقة توافق الذاكرة التنفيذية**: `w_mmap/w_munmap/w_mprotect` فوق `VirtualAlloc/VirtualProtect` — يفعّل الـ JIT على ويندوز (كانت الدوال POSIX فقط).
2. **`os_heap_tune()`**: تفعيل كومة الذاكرة منخفضة التجزؤ (LFH) عند الإقلاع.
3. **تعريف `mallopt`** كعملية لا-عمل على ويندوز (كان يمنع الترجمة أصلاً).
