# سولان (Solan) — لغة برمجة عربية

سولان لغة برمجة كاملة بالعربية: كلماتها المفتاحية ودوالها ومكتباتها ورسائل أخطائها كلها عربية، وتعمل كملف تنفيذي واحد بلا مفسّر خارجي.

```
خل اسم = "عالم"
اطبع("مرحبا يا ${اسم}")
```

**الإصدار الحالي: 1.0.0**

هذا الملف هو التوثيق الوحيد للغة: التثبيت، التشغيل، تعلّم اللغة، المرجع الكامل لكل دالة ومكتبة، كتابة المكتبات ونشرها وتنزيلها، والأدوات.

## 1) التثبيت

### المتطلبات

| الشيء | متى يلزم |
|---|---|
| مترجم C (`gcc` أو `clang`) | للبناء فقط. لا يلزم `make` ولا أي أداة بناء أخرى |
| OpenSSL 3 (`libssl`) | لـ `https` و`wss` فقط (يُحمَّل وقت التشغيل إن وُجد) |
| `git` (الإصدار 2.x) | لأوامر الحزم `add` و`install` و`update` و`outdated` و`publish` فقط. تشغيل البرامج بعدها لا يحتاجه |

### الطريقة السريعة (Linux / macOS / BSD)

```bash
git clone https://github.com/kingxsolo/Solan.git solan && cd solan
sh install.sh
```

يكتشف السكربت نظامك ومدير الحزم، ويحاول تثبيت مترجم C الناقص فقط عند الحاجة، ثم يبني الملف التنفيذي ويثبّته في `/usr/local/bin` أو `~/.local/bin`. المكونات الاختيارية لا تُثبّت تلقائيًا، ويُضمَّن SQLite فقط إذا كانت ملفاته موجودة مسبقًا. ثم:

```bash
solan --version
solan -e 'اطبع("هلا يا عالم")'
```

إن ظهر تنبيه أن مجلد التثبيت ليس في `PATH` فأضفه:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.profile
```

### خيارات install.sh

| الخيار | الوظيفة |
|---|---|
| `--prefix DIR` | مكان التثبيت |
| `--no-deps` | لا تحاول تثبيت المترجم تلقائيًا |
| `--no-sqlite` | لا تضمّن SQLite (يُحمَّل من النظام وقت التشغيل) |
| `--build-only` | ابنِ `./solan` فقط بلا تثبيت |
| `--uninstall` | احذف `solan` من مكان التثبيت |
| `--target NAME` | افرض المنصة: `linux` أو `macos` أو `bsd` أو `windows` أو `android` (للبناء عبر منصات مع `CC`) |
| `--dry-run` | اعرض ما سيفعله بلا تنفيذ |

يحترم السكربت المتغيرات `CC` و`CFLAGS` و`CPPFLAGS` و`LDFLAGS`. أمثلة:

```bash
CC=clang sh install.sh --build-only                                     # مترجم محدد
CFLAGS="-DSOLAN_JIT=0" sh install.sh --build-only                       # بلا جيت
CC=x86_64-w64-mingw32-gcc sh install.sh --build-only --target windows   # بناء لويندوز
sh install.sh --uninstall                                               # إزالة
```

### تثبيت المتطلبات يدوياً

المطلوب للبناء هو مترجم C فقط. يختار `install.sh` مدير الحزم تلقائيًا ويحاول أكثر من طريقة مناسبة للنظام. يمكن تثبيت OpenSSL اختياريًا لتفعيل `https` و`wss`، وتتوفر SQLite من النظام عند عدم تضمينها.

### Windows

داخل **MSYS2 UCRT64**: ثبّت المترجم (`pacman -S --needed mingw-w64-ucrt-x86_64-gcc`) ثم نفّذ `sh install.sh --target windows`. أو من PowerShell شغّل `install.ps1` الذي يتولى ذلك. لـ `https` ضع `libssl-3-x64.dll` بجوار `solan.exe`. على ويندوز يلزم تفعيل «Long Paths» أو جعل `SOLAN_HOME` قصيراً (مثل `C:\so`) لمسارات الحزم الطويلة.

### متغيرات البيئة

| المتغير | الوظيفة |
|---|---|
| `SOLAN_HOME` | مكان مخزن المكتبات (الافتراضي `~/.solan`) |
| `SOLAN_PATH` | مسارات إضافية للبحث عن الوحدات |
| `SOLAN_SAFE` | إن كانت غير فارغة وليست `0` فالتشغيل بوضع آمن (قراءة وبيئة فقط) |
| `SOLAN_LIBSSL` | مسار مكتبة OpenSSL صراحة |
| `SOLAN_JIT` | `0` لتعطيل المجمّع الفوري وقت التشغيل |
| `NO_COLOR` | لتعطيل الألوان في الطرفية |
| `PREFIX` | يحدد مكان تثبيت الملف التنفيذي|

## 2) تشغيل اللغة

### تشغيل ملف أو كود

```bash
solan ملف.سو              # تشغيل ملف (الامتدادات: .سو و .an و .solan)
solan ملف.سو وسيط1 وسيط2  # الوسائط تظهر في المتغير العام «وسائط»
solan -e 'اطبع(1 + 2)'    # تشغيل كود مباشر
solan                      # الوضع التفاعلي (REPL)
```

في الوضع التفاعلي يُعرض ناتج كل تعبير تلقائياً، ويدعم الإدخال متعدد الأسطر (الأقواس غير المغلقة تُكمَل بسطر `...`)، والتاريخ إن توفرت `readline`. للخروج اكتب `خروج` أو `exit` أو اضغط `Ctrl+D`.

يجوز أن يبدأ الملف بسطر `#!/usr/bin/env solan` ليكون قابلاً للتنفيذ مباشرة.

### كل أوامر وخيارات سطر الأوامر

| الأمر | الوظيفة |
|---|---|
| `solan ملف.سو [وسائط...]` | تشغيل ملف |
| `solan -e "كود"` | تشغيل كود مباشر |
| `solan` | الوضع التفاعلي |
| `solan --check ملف.سو` | فحص الصياغة بلا تشغيل (يطبع «سليم» أو الخطأ) |
| `solan fmt ملف.سو [-w]` | تنسيق الكود: إزاحة مسافتين لكل مستوى، حذف الفراغات الزائدة في نهاية الأسطر وتقليص الأسطر الفارغة المتكررة (`-w` يكتبه في الملف، وإلا يطبعه) |
| `solan fmt ملف.سو --قياسي [-w]` | استبدال مرادفات **الكلمات المفتاحية** بالكلمة القياسية (انظر [المرادفات](#7-المرادفات)) |
| `solan --لون ملف.سو` | عرض الكود ملوّناً في الطرفية (`--html` يصدّر صفحة HTML) |
| `solan --تتبع ملف.سو` | طباعة كل سطر ينفَّذ |
| `solan --تصحيح ملف.سو [--نقطة N]` | مصحّح تفاعلي خطوة بخطوة (ونقطة توقف عند السطر N) |
| `solan --ops ملف.سو` | عرض التعليمات الداخلية المترجمة (للمطورين) |
| `solan lsp` | خادم اللغة (LSP) للمحررات |
| `solan -v` / `--version` | الإصدار |
| `solan -h` / `--help` | المساعدة |
| `solan init` · `add` · `install` · `remove` · `update` · `list` · `outdated` · `why` · `verify` · `prune` · `cache clean` · `publish` | أوامر الحزم (القسم 9) |

**خيارات عامة تُوضع قبل اسم الملف:**

| الخيار | الوظيفة |
|---|---|
| `--اسمح=...` / `--امنع=...` | الصلاحيات (القسم 8) |
| `--آمن` | وضع آمن: قراءة وبيئة فقط |
| `--حد_وقت N` | إنهاء البرنامج بعد N ثانية |
| `--حد_ذاكرة N` | حد الذاكرة بالميغابايت |
| `--بلا_لون` | تعطيل الألوان |

الأسماء الإنجليزية المكافئة: `--trace` و`--debug` و`--safe` و`--allow` و`--deny` و`--timeout` و`--max-mem` و`--no-color` و`--break` و`--color`.

### رموز الخروج

`0` نجاح · `65` خطأ في الصياغة · `66` تعذّر فتح الملف · `70` خطأ تشغيل غير ممسوك · `64` خيار صلاحيات غير صالح. وللخروج برمز مخصص من البرنامج: `نظام.اخرج(رمز)`.

### أول برنامج

أنشئ ملفاً `هلا.سو`:

```
خل اسم = ادخل("ما اسمك؟ ")
اطبع("أهلا يا ${اسم}!")
لكل ر في مدى(1, 4) {
  اطبع("العدّ ${ر}")
}
```

ثم `solan هلا.سو`.

## 3) تعلّم اللغة

> كل الأمثلة هنا جُرِّبت فعلاً على الإصدار 1.0.0. المخرجات المكتوبة بعد `//` هي ما يطبعه البرنامج.

### 3.1) الأساسيات

**التعليقات:** `// سطر` و`/* متعدد الأسطر */`.

**الفاصلة المنقوطة اختيارية.** نهاية السطر تكفي، ويجوز وضع أكثر من تعليمة في سطر بـ `;` (أو `؛`). الفاصلة العربية `،` تعمل مثل `,`.

**الأسماء:** حروف عربية أو لاتينية وأرقام و`_`، ولا تبدأ برقم. اللغة **تطبّع** الأسماء: لا فرق بين `أ` و`إ` و`آ` و`ا`، ولا بين `ة` و`ه`، ولا بين `ى` و`ي`، ولا التشكيل. فـ `قيمة` و`قيمه` اسم واحد (وهذا يظهر في رسائل الأخطاء وفي `نوع()` لأسماء الأصناف: `قطة` تظهر `قطه`). النصوص بين علامات الاقتباس لا تُطبَّع.

**المتغيرات والثوابت:**

```
خل اسم = "سلمى"        // متغير
ثابت باي_تقريبي = 3.14  // ثابت: محاولة إعادة إسناده خطأ صياغة قبل التشغيل
اسم = "ليلى"           // إعادة الإسناد مسموحة للمتغير
خل س                    // بلا قيمة ابتدائية = عدم
```

**الأنواع الأساسية:**

| النوع | أمثلة | `نوع(x)` |
|---|---|---|
| رقم (عشري مزدوج) | `5` `3.5` `1e3` `0xFF` `1_000_000` `٣٫٥` | `رقم` |
| نص | `"سلام"` `'سلام'` `«سلام»` | `نص` |
| منطقي | `صح` `غلط` | `منطقي` |
| عدم | `عدم` | `عدم` |
| قائمة | `[1, 2, 3]` | `قائمة` |
| قاموس | `{"أ": 1}` | `قاموس` |
| دالة | `دالة() { }` | `دالة` |
| وعد | `وعد()` | `وعد` |
| كائن من صنف | `قطة("ميمي")` | اسم الصنف |

الأرقام كلها أعداد عشرية مزدوجة (double): الأعداد الصحيحة دقيقة حتى `9007199254740992`، وما فوقها يرفضه المحلل (استعمل مكتبة `ضخم`). يمكن كتابة الأرقام بالأرقام الهندية `٠-٩` والفارسية `۰-۹` و`٫` فاصلة عشرية، و`_` للفصل داخل الأرقام. لعرض ناتج الأرقام هندية استعمل `ارقام_الاخراج("عربي")`.

**النصوص:**

```
خل ن = "سلمى"
اطبع("مرحبا ${ن}، ${2 + 3} أيام")    // مرحبا سلمى، 5 أيام   ← ${...} تقبل أي تعبير
اطبع("سطر1\nسطر2\tتاب \"اقتباس\" \\ \$")  // الهروب: \n \t \" \\ \$
اطبع("نص طويل
على عدة أسطر")                        // النص يمتد عبر الأسطر
اطبع("ab" * 3, "أ" + "ب")              // ababab أب
```

**لا تحويل ضمني بين النص والرقم:** `"أ" + 1` يرمي خطأ. استعمل `"أ" + نص(1)` أو `"أ${1}"`. المقارنة بين نوعين مختلفين لا تتحقق (`"1" == 1` غلط).

**العوامل (من الأقوى ارتباطاً إلى الأضعف تقريباً):**

| العامل | المعنى |
|---|---|
| `**` | أس (`2 ** 10` = 1024) |
| `*` `×` `/` `÷` `\` `%` | ضرب، قسمة عشرية، **قسمة صحيحة** (`7 \ 2` = 3 و`-7 \ 2` = -4)، باقي (`-5 % 3` = 1: باقي موجب كما في بايثون) |
| `+` `-` | جمع وطرح (والجمع يدمج النصوص والقوائم) |
| `<<` `>>` `&` `^` `\|` | عمليات على البتات |
| `<` `<=` `>` `>=` `==` `!=` | مقارنة (القوائم والقواميس تُقارَن بالمحتوى) |
| `في` | عضوية: `"ب" في "أبج"` و`س في قائمة` و`"مفتاح" في قاموس` |
| `ليس` `!` | نفي منطقي |
| `و` `&&` | «و» (كسولة) |
| `او` `\|\|` | «أو» (كسولة) |
| `? :` أو `؟ :` | الشرط الثلاثي: `شرط ? أ : ب` |
| `??` أو `؟؟` | القيمة الافتراضية إن كان اليسار `عدم`: `س ?? "افتراضي"` |
| `?.` أو `؟.` | وصول آمن: `م?.أ` يعطي `عدم` إن كان `م` عدماً (لا يحمي من مفتاح مفقود في قاموس) |
| `=` `+=` `-=` `*=` `/=` `\=` `%=` `**=` `++` `--` | الإسناد |

**الصحة والخطأ المنطقي:** القيم «الكاذبة» هي `غلط` و`عدم` و`0` والنص الفارغ `""` والقائمة الفارغة والقاموس الفارغ؛ ما سواها «صادق».

### 3.2) الشروط

```
خل أ = 7
اذا أ > 100 {
  اطبع("مئة")
} والا_اذا أ > 5 {
  اطبع("أكبر من خمسة")
} والا {
  اطبع("لا")
}
اطبع(أ > 5 ? "كبير" : "صغير")
```

**التبديل** (لا يسقط من حالة لأخرى؛ كل حالة كتلة مستقلة، وتقبل عدة قيم):

```
تبديل أ {
  حالة 1 { اطبع("واحد") }
  حالة 2, 3 { اطبع("اثنان أو ثلاثة") }
  افتراضي { اطبع("غير ذلك") }
}
```

### 3.3) الحلقات

```
طالما س < 3 { س++ }                  // طالما: ما دام الشرط صادقاً
كرر 3 { اكتب("ه") }                  // كرر N مرة: ههه
لكل ر في مدى(0, 10, 4) { اطبع(ر) }  // 0 ثم 4 ثم 8  (مدى(أ، ب، خطوة): الخطوة اختيارية وقد تكون سالبة)
لكل ح في "سلام" { اطبع(ح) }          // على حروف النص
لكل ع في [10, 20] { اطبع(ع) }
لكل ك, ق في {"x": 1, "y": 2} { اطبع(ك, ق) }   // x 1 ثم y 2  (مفتاح وقيمة)
لكل ف, ق في ["a", "b"] { اطبع(ف, ق) }         // 0 a ثم 1 b  (فهرس وقيمة)
```

`توقف` تخرج من الحلقة و`استمر` تنتقل إلى التكرار التالي. `مدى` داخل `لكل` كسولة ولا تبني قائمة (يمكن `مدى(0, 30000000)`)، أما خارج `لكل` فتبني قائمة (حدها 10 ملايين عنصر).

### 3.4) الدوال

```
دالة جمع(أ, ب = 2) { ارجع أ + ب }       // معامل افتراضي
اطبع(جمع(1), جمع(1, 5))                   // 3 6

دالة مجموع(...ارقام) {                    // معاملات متبقية ...
  خل ج = 0
  لكل ر في ارقام { ج += ر }
  ارجع ج
}
اطبع(مجموع(1, 2, 3), مجموع(...[4, 5]))   // 6 9   ← ... في الاستدعاء تفرد القائمة

خل ضعف = دالة(س) { ارجع س * 2 }          // دالة مجهولة
خل ثلاثة = (س) => س * 3                  // دالة سهمية (التعبير هو الناتج)
خل اربعة = س => س * 4

دالة عداد() {                             // إغلاقات (closures)
  خل ع = 0
  ارجع دالة() { ع++; ارجع ع }
}
خل ع1 = عداد(); ع1()
اطبع(ع1())                                // 2
```

الدوال قيم عادية: تُمرَّر وتُعاد وتُخزَّن. دالة بلا `ارجع` تعيد `عدم`. الدوال يمكن أن تتداخل. ملاحظة: أسماء مثل `و` و`او` و`ليس` و`في` كلمات محجوزة ولا تصلح اسماء معاملات أو متغيرات.

**الأنواع الاختيارية** (تُفحص وقت التشغيل، وتُحذف بلا أثر إن لم تكتبها):

```
خل س: رقم = 5
دالة جمع2(أ: رقم, ب: رقم = 2): رقم { ارجع أ + ب }
دالة اسم(ن: نص? = عدم): نص { ارجع ن ?? "افتراضي" }   // ? تعني: أو عدم
خل م: رقم | نص = "ا"                                    // اتحاد أنواع
خل ق: قائمة<رقم> = [1, 2]                               // يُفحص الحاوية فقط لا العناصر
خل ز = (أ: رقم): رقم => أ * 2
```

الأنواع المعروفة: `رقم` (= `عدد`)، `عدد_صحيح`، `نص`، `منطقي`، `قائمة`، `قاموس`، `دالة`، `عدم`، `اي`، `كائن`، `صنف`، `كوروتين`، وأي اسم صنف (يشمل الأصناف الوارثة). عند المخالفة: `خطأ في النوع: المتغير 'س' يتوقع 'رقم' لكن وجدت 'نص'`.

### 3.5) القوائم

```
خل ق = [3, 1, 2]
اطبع(ق[0], ق[-1], ق.طول, طول(ق))     // 3 2 3 3   (الفهرس السالب من النهاية)
ق[0] = 9
خل [أ, ب] = [1, 2]                      // تفكيك عند التعريف
[أ, ب] = [ب, أ]                          // تبديل قيمتي متغيرين (تفكيك بالإسناد)
خل ك = [...[1, 2], 3, ...[4]]           // [1، 2، 3، 4]  (نشر القوائم)
اطبع([1] + [2], [0] * 3)                // [1، 2]  [0، 0، 0]
```

الفهرس خارج النطاق يرمي خطأ: `فهرس القائمة غير صالح أو خارج النطاق`. طرق القوائم في القسم 4.

### 3.6) القواميس

```
خل م = {"أ": 1, "ب": 2}
اطبع(م["أ"], م.أ)                       // 1 1   (الوصول بالنقطة للمفاتيح النصية)
م["ج"] = 3
اطبع("ب" في م, م.احصل("د", 0))          // صح 0   (احصل مع قيمة افتراضية)
خل {الاسم, العمر} = {"الاسم": "سلمى", "العمر": 30}    // تفكيك قاموس
خل ن = {...م, "ه": 5}                   // نشر قاموس
```

ترتيب الإدخال محفوظ. **المفتاح غير الموجود يرمي خطأ** (`المفتاح 'ب' غير موجود في القاموس`)، فاستعمل `.احصل(مفتاح، افتراضي)` أو `في` للفحص قبل القراءة. المفاتيح يمكن أن تكون نصوصاً أو أرقاماً.

### 3.7) الأصناف والوراثة

```
صنف حيوان {
  دالة بناء(اسم) { هذا.اسم = اسم }          // المُنشئ اسمه «بناء»
  دالة صوت() { ارجع "..." }
  دالة عرف() { ارجع هذا.اسم + " يقول " + هذا.صوت() }
  ساكن دالة نوع_عام() { ارجع "حيوان" }       // عضو ساكن (يُستدعى على الصنف)
  خاصية الاسم_كبير() { ارجع هذا.اسم.كبير() } // خاصية (getter) بلا أقواس عند القراءة
}
صنف قطة يرث حيوان {                          // أو: صنف قطة : حيوان
  دالة صوت() { ارجع "مياو" }
  دالة عرف() { ارجع الاب.عرف() + "!" }      // الاب = الصنف الأب
}
خل ق = قطة("ميمي")
اطبع(ق.عرف())                                // ميمي يقول مياو!
اطبع(حيوان.نوع_عام(), ق.الاسم_كبير)         // حيوان ميمي
اطبع(هل_فرع(ق, حيوان), نوع(ق), لديه(ق, "اسم"))   // صح قطه صح
```

`هذا` هو الكائن الحالي. الخصائص تُنشأ بالإسناد `هذا.س = ...` داخل `بناء` أو أي دالة. استدعاء صنف بوسائط وهو بلا `بناء` خطأ.

### 3.8) التعداد

```
تعداد لون { احمر, اخضر = 5, ازرق }
اطبع(لون.احمر, لون.اخضر, لون.ازرق)   // 0 5 6   (يستمر العدّ بعد القيمة المحددة)
```

### 3.9) معالجة الأخطاء

```
حاول {
  ارمي "خطأ تجريبي"             // ارمي: يمكن رمي أي قيمة (غالباً نص)
} امسك (خ) {                      // الأقواس حول اسم المتغير اختيارية
  اطبع("امسكت:", خ)
} اخيرا {
  اطبع("تنفَّذ دائماً")
}
```

أخطاء التشغيل الداخلية تُمسَك كنصوص عربية: `القسمة على صفر` و`المفتاح 'ب' غير موجود في القاموس` و`المتغير 'س' غير معرّف` و`لا يمكن الطرح بين 'نص' و 'رقم'`. الخطأ غير الممسوك يطبع رسالة مع رسم للسطر ومكدس الاستدعاء وينهي البرنامج برمز `70`. `تأكد(شرط، رسالة)` يرمي الرسالة إن كان الشرط كاذباً.

### 3.10) المولّدات والكوروتينات

```
مولد دالة عد(ن) {                      // دالة مولّدة: تنتج قيماً واحدة بعد أخرى
  لكل ي في مدى(0, ن) { انتج ي }
}
لكل ع في عد(3) { اطبع(ع) }             // 0 1 2

خل ر = كوروتين(دالة() { انتج 1; انتج 2; ارجع 3 })    // كوروتين يدوي
اطبع(استأنف(ر))   // 1
اطبع(استأنف(ر))   // 2
اطبع(منتهي(ر))    // غلط (ينتهي بعد الاستئناف الثالث)
```

### 3.11) البرمجة غير المتزامنة

`غير_متزامن دالة` تعيد **وعداً**، و`انتظر` توقف الدالة حتى يكتمل الوعد. حلقة أحداث واحدة تدير كل شيء (مؤقتات، شبكة، عمليات فرعية) بلا خيوط.

```
غير_متزامن دالة مهمة(اسم, ثواني) {
  انتظر نم(ثواني)                       // نم: وعد ينتهي بعد المدة
  ارجع "انتهت ${اسم}"
}
غير_متزامن دالة رئيسي() {
  خل نتائج = انتظر كل_الوعود([مهمة("أ", 0.3), مهمة("ب", 0.3)])   // بالتوازي: ~0.3 ثانية
  اطبع(نتائج)
  اطبع(انتظر عملية(دالة() { ارجع 6 * 7 }))   // عملية ثقيلة في عملية فرعية: 42
}
شغل(رئيسي)                              // شغل: يشغّل الدالة وينتظر انتهاءها
```

المرجع الكامل للوعود (`وعد` و`.ثم` و`.التقط` و`كل_الوعود` و`سباق`...) في القسم 4. وللعمل الموازي على أنوية المعالج انظر مكتبة `عمال`.

### 3.12) الوحدات والاستيراد

الاستيراد يكون **في المستوى الأعلى للملف فقط**:

```
استورد "رياضيات"                        // مكتبة مدمجة أو قياسية
اطبع(رياضيات.جذر(16))                   // 4

استورد "رياضيات" باسم ر                 // باسم آخر
من "رياضيات" استورد جذر, باي            // استيراد أسماء محددة
من "رياضيات" استورد جذر باسم ج, باي

استورد "./وحدة"                         // ملف نسبي (يُربط باسم الملف: وحدة)
استورد "./مجلد/اداة" باسم اداة
```

**كل ما يُعرَّف في المستوى الأعلى من الملف يصبح عضواً في الوحدة** (دوال ومتغيرات وأصناف). لا توجد كلمة `export`. ملف `وحدة.سو`:

```
خل ثابتي = 5
دالة سلم() { ارجع "من الوحدة" }
اذا هو_الرئيسي { اطبع("اشتغلت مباشرة") }   // يُنفَّذ فقط عند تشغيل الملف مباشرة لا عند استيراده
```

- المتغير العام `هو_الرئيسي` يكون `صح` في الملف المشغَّل مباشرة و`غلط` في الوحدات المستوردة.
- الوحدة تُحمَّل مرة واحدة وتُخزَّن. الاستيراد الدائري آمن (لا حلقة لا نهائية).
- يُبحث عن الاسم بهذا الترتيب: مسار نسبي ← مكتبة مدمجة/قياسية ← اعتماديات المشروع من `solan.lock` ← المسارات القديمة (`SOLAN_PATH` ثم `~/.solan/modules/` ثم `$PREFIX/lib/solan/`). والامتدادات المجرَّبة: بلا امتداد، `.سو`، `.an`، `.solan`، ثم مجلد فيه `رئيسي.سو`.
- الاستيراد النسبي داخل مكتبة يُحسب نسبةً إلى **الملف الذي فيه الاستيراد**.

### 3.13) أنماط شائعة

**قراءة وكتابة ملف:**

```
استورد "ملفات"
ملفات.اكتب("ملاحظات.txt", "سطر1\nسطر2\n")
ملفات.الحق("ملاحظات.txt", "سطر3\n")
لكل س في ملفات.سطور("ملاحظات.txt") { اطبع(س) }
```

**JSON:**

```
استورد "جيسون"
خل نص_ج = جيسون.ترميز({"أ": [1, 2, {"ب": صح}]})
اطبع(نص_ج)                 // {"أ":[1,2,{"ب":true}]}
اطبع(جيسون.فك(نص_ج).أ[1]) // 2
```

**طلب HTTP:**

```
استورد "شبكة"
خل ر = شبكة.جلب("https://api.example.com/data", {"رؤوس": {"Accept": "application/json"}})
اذا ر.ناجح { اطبع(جيسون.فك(ر.جسم)) } والا { اطبع("فشل:", ر.حالة) }
```

**خادم ويب صغير:**

```
استورد "شبكة"
دالة معالج(طلب) {
  اذا طلب.مسار == "/api" { ارجع {"جسم": {"طريقة": طلب.طريقة}} }   // قاموس في الجسم يُرسَل JSON
  ارجع "<h1>مرحبا ${طلب.استعلام.احصل("اسم", "يا غريب")}</h1>"      // نص يُرسَل HTML
}
شبكة.خادم(8080, معالج)
```

**قاعدة بيانات SQLite:**

```
استورد "قاعدة"
خل ق = قاعدة.افتح("بيانات.db")
قاعدة.نفذ(ق, "CREATE TABLE IF NOT EXISTS رسائل(id INTEGER PRIMARY KEY, نص TEXT)")
قاعدة.نفذ(ق, "INSERT INTO رسائل(نص) VALUES (?)", ["مرحبا"])
لكل صف في قاعدة.استعلم(ق, "SELECT * FROM رسائل") { اطبع(صف.نص) }
قاعدة.اغلق(ق)
```

## 4) المرجع: الكلمات والمتغيرات والدوال المدمجة

### 4.1) الكلمات المفتاحية

كل كلمة تقبل مرادفات (القسم 7) ولا فرق في الهمزات ولا `ة`/`ه`. هذه الكلمات **القياسية**:

| الكلمة | الوظيفة |
|---|---|
| `خل` | تعريف متغير |
| `ثابت` | تعريف ثابت |
| `دالة` | تعريف دالة |
| `ارجع` | إرجاع قيمة من دالة |
| `اذا` · `والا_اذا` · `والا` | الشرط |
| `طالما` | حلقة بشرط |
| `كرر` | تكرار عدد مرات |
| `لكل` … `في` | حلقة على عناصر |
| `توقف` · `استمر` | الخروج من الحلقة / التكرار التالي |
| `تبديل` · `حالة` · `افتراضي` | تبديل متعدد الحالات (`حالة` و`افتراضي` سياقيتان) |
| `تعداد` | تعريف تعداد |
| `صح` · `غلط` · `عدم` | القيم الثابتة |
| `و` · `او` · `ليس` | العوامل المنطقية |
| `صنف` · `هذا` · `الاب` · `يرث` | الأصناف (و`ساكن` و`خاصية` سياقيتان) |
| `حاول` · `امسك` · `اخيرا` · `ارمي` | الأخطاء |
| `استورد` · `باسم` · `من` | الاستيراد (`من` سياقية) |
| `غير_متزامن` · `انتظر` | البرمجة غير المتزامنة |
| `مولد` · `انتج` | المولّدات |

الكلمات السياقية (`حالة`، `افتراضي`، `ساكن`، `خاصية`، `تعداد`، `من`) لا تُحجز: يجوز استعمالها أسماء متغيرات خارج سياقها. أما الكلمات المحجوزة فلا تصلح أسماء متغيرات أو معاملات (ومن أخطاء المبتدئين: `و` و`او` و`ليس` و`في` و`فارغ` و`صحيح` و`نهاية` و`حالة`...).

### 4.2) المتغيرات العامة (متاحة دائماً)

| الاسم | القيمة |
|---|---|
| `وسائط` | قائمة نصوص: وسائط سطر الأوامر بعد اسم الملف |
| `هو_الرئيسي` | `صح` إن كان الملف مشغَّلاً مباشرة، `غلط` إن كان مستورداً |
| `اسم_الملف` | اسم الملف المشغَّل |
| `النسخة` | نص إصدار اللغة (`1.0.0`) |
| `نظام` · `جيسون` · `شبكة` · `سوكت` · `حلقة` | هذه المكتبات الخمس مستوردة تلقائياً (لا تحتاج `استورد`) |
| `وعد` | صنف الوعود (انظر 4.4) |

### 4.3) الدوال المدمجة

| الدالة | الوظيفة |
|---|---|
| `اطبع(...قيم)` | تطبع القيم مفصولة بمسافة وتنهي بسطر جديد |
| `اكتب(...قيم)` | مثل `اطبع` بلا سطر جديد |
| `ادخل(سؤال؟)` | تقرأ سطراً من الإدخال (تعرض `سؤال` أولاً إن أُعطي). تعيد `عدم` عند نهاية الإدخال |
| `طول(x)` | عدد حروف النص / عناصر القائمة / مفاتيح القاموس |
| `نوع(x)` | اسم النوع: `رقم` `نص` `منطقي` `قائمة` `قاموس` `عدم` `دالة` `وعد`، أو اسم الصنف لكائنات الأصناف |
| `نص(x)` | تحويل أي قيمة إلى نص |
| `رقم(x)` | تحويل نص إلى رقم (يعيد `عدم` إن لم يكن رقماً)، و`رقم(صح)` = 1 |
| `مدى(نهاية)` · `مدى(بداية, نهاية)` · `مدى(بداية, نهاية, خطوة)` | قائمة أرقام (النهاية مستثناة، الخطوة قد تكون سالبة). كسولة داخل `لكل` |
| `تأكد(شرط, رسالة؟)` | ترمي الرسالة إن كان الشرط كاذباً |
| `حرف(رمز)` · `رمز(حرف)` | الحرف من رمزه (`حرف(65)` = `A`) والعكس |
| `هل_نص(x)` `هل_رقم(x)` `هل_قائمة(x)` `هل_قاموس(x)` `هل_عدم(x)` `هل_دالة(x)` `هل_وعد(x)` | فحص النوع |
| `هل_فرع(كائن, صنف)` | هل الكائن من الصنف أو من وارث منه |
| `لديه(كائن, اسم)` | هل لكائن الصنف هذه الخاصية أو الدالة |
| `نسق(قالب, ...قيم)` | تنسيق نص (انظر أدناه) |
| `لون_الكود(نص)` · `كود_html(نص)` | تلوين شيفرة سولان بألوان الطرفية (ANSI) أو بصفحة HTML |
| `ارقام_عربية(نص)` · `ارقام_لاتينية(نص)` · `ارقام_فارسية(نص)` | تحويل الأرقام داخل نص إلى هندية / لاتينية / فارسية |
| `ارقام_الاخراج(نمط)` | يغيّر طريقة عرض الأرقام في كل المخرجات: `"عربي"` (أو `"ar"`) هندية، `"فارسي"` (أو `"fa"`) فارسية، وأي شيء آخر لاتينية |
| `كوروتين(دالة)` | ينشئ كوروتيناً من دالة تستعمل `انتج` |
| `استأنف(كوروتين, قيمة؟)` | يكمل الكوروتين حتى `انتج` التالي ويعيد القيمة المنتَجة |
| `منتهي(كوروتين)` | هل انتهى الكوروتين |
| `وعد()` | ينشئ وعداً جديداً (انظر 4.4) |
| `نم(ثواني)` | وعد ينتهي بعد المدة (مع `انتظر`) |
| `كل_الوعود(قائمة)` | وعد يكتمل حين تكتمل كلها، ونتيجته قائمة النتائج بنفس الترتيب (العناصر غير الوعود تُقبل كما هي) |
| `سباق(قائمة)` | وعد يكتمل بنتيجة أول وعد ينتهي |
| `شغل(دالة)` | يشغّل الدالة، وإن أعادت وعداً ينتظره ويعيد نتيجته (نقطة بداية البرامج غير المتزامنة) |
| `عملية(دالة)` | يشغّل الدالة في عملية فرعية ويعيد وعداً بنتيجتها (النتيجة يجب أن تكون قابلة لترميز JSON) |
| `جلب_غير_متزامن(رابط, خيارات؟)` | `شبكة.جلب` لكن بوعد (لا يحجب الحلقة) |
| `خادم_حلقة(منفذ, معالج, خيارات؟)` | خادم HTTP على حلقة الأحداث، والمعالج قد يكون `غير_متزامن` (وهو نفسه `شبكة.خادم_حلقة`) |

**قوالب `نسق`:**

| القالب | المعنى | مثال | الناتج |
|---|---|---|---|
| `{}` | القيمة التالية | `نسق("{} من {}", 3, 10)` | `3 من 10` |
| `{0}` `{1}` | قيمة بالترتيب | `نسق("{0} {1} {0}", "أ", "ب")` | `أ ب أ` |
| `{:.2f}` | عشري بعدد خانات | `نسق("{:.2f}", 3.14159)` | `3.14` |
| `{:5}` `{:<5}` `{:>5}` `{:^5}` | عرض: افتراضي، يسار، يمين، وسط | `نسق("{:>5}|{:<5}|", 1, 2)` | `    1|2    |` |
| `{:05d}` | صحيح بأصفار بادئة | `نسق("{:05d}", 42)` | `00042` |
| `{:x}` `{:b}` | ست عشري، ثنائي | `نسق("{:x} {:b}", 255, 5)` | `ff 101` |

### 4.4) الوعود

الوعد كائن من الصنف `وعد` يمثل نتيجة ستصل لاحقاً.

| العضو | الوظيفة |
|---|---|
| `وعد()` | وعد جديد غير مكتمل |
| `.حل(قيمة)` | يكمله بالقيمة (ويعيد الوعد نفسه) |
| `.ارفض(خطأ)` | يكمله بفشل |
| `.ثم(دالة)` | وعد جديد نتيجته `دالة(القيمة)` |
| `.التقط(دالة)` | وعد جديد يعالج الفشل: نتيجته `دالة(الخطأ)` |
| `.منجز` · `.قيمة` · `.فشل` · `.خطأ` | الحالة: هل اكتمل، قيمته، هل فشل، سبب الفشل |

```
غير_متزامن دالة رئيسي() {
  خل وع = وعد()
  حلقة.بعد(0.1, دالة() { وع.حل("وصلت") })    // مؤقت يكمل الوعد بعد 0.1 ثانية
  اطبع(انتظر وع)                             // وصلت
  اطبع(انتظر وعد().حل(2).ثم(س => س * 10))   // 20
}
شغل(رئيسي)
```

إن فشل وعد داخل `انتظر` يُرمى خطأه ويمكن مسكه بـ `حاول`/`امسك`.

### 4.5) طرق النصوص

| الطريقة | الوظيفة |
|---|---|
| `.طول` | عدد الحروف (خاصية، وكذلك `طول(نص)`) |
| `.قسم(فاصل؟)` | قائمة أجزاء (بلا فاصل: يقسم عند الفراغات) — `"a,b".قسم(",")` ← `["a","b"]` |
| `.نظف()` | يحذف الفراغات من الطرفين |
| `.كبير()` · `.صغير()` | حروف كبيرة / صغيرة |
| `.يبدأ_ب(ن)` · `.ينتهي_ب(ن)` · `.يحتوي(ن)` | فحوص (تعيد `صح`/`غلط`) |
| `.ابدل(قديم, جديد)` | يستبدل **كل** الورود |
| `.جزء(من, الى؟)` | نص جزئي (`الى` مستثناة، والسالب من النهاية): `"abcdef".جزء(1, 4)` ← `bcd`، `.جزء(-3)` ← `def` |
| `.ابحث(ن)` | فهرس أول ورود أو `-1` |
| `.كرر(ن)` | يكرر النص (وكذلك `"ab" * 3`) |
| `.اعكس()` | عكس النص (تُعيد نصاً جديداً) |
| `.حروف()` | قائمة الحروف |
| `.سطور()` | قائمة الأسطر |
| `.املأ_يسار(عرض, حرف)` · `.املأ_يمين(عرض, حرف)` | حشو حتى العرض: `"5".املأ_يسار(3, "0")` ← `005` |
| `.نسق(...قيم)` | نفس `نسق` والنص هو القالب |
| `[ف]` | الحرف عند الفهرس: `"abc"[1]` ← `b` |

### 4.6) طرق القوائم

| الطريقة | الوظيفة |
|---|---|
| `.طول` | عدد العناصر |
| `.اضف(x)` | يضيف في النهاية (تعدّل القائمة) |
| `.ادرج(فهرس, x)` | يدرج قبل الفهرس |
| `.احذف(فهرس)` | يحذف العنصر عند الفهرس |
| `.اسحب()` | يحذف آخر عنصر ويعيده |
| `.رتب(مقارن؟)` | **يرتّب القائمة نفسها** ويعيدها. المقارن `(أ, ب) => رقم` (سالب: أ أولاً) |
| `.اعكس()` | **يعكس القائمة نفسها** ويعيدها (للنسخة: `ق.انسخ().اعكس()`) |
| `.ادمج(فاصل)` | يدمج العناصر في نص |
| `.حول(دالة)` | قائمة جديدة بنتيجة الدالة على كل عنصر |
| `.رشح(دالة)` | قائمة جديدة بالعناصر التي تعيد فيها الدالة صادقاً |
| `.اطوي(دالة, بداية؟)` | تجميع: `[1,2,3].اطوي((أ, ب) => أ + ب, 0)` ← `6` |
| `.نفذ(دالة)` | يستدعي الدالة على كل عنصر |
| `.جد(دالة)` | أول عنصر تحقق دالته أو `عدم` |
| `.اي(دالة)` · `.كل(دالة)` | هل يحقق بعض العناصر / كلها الدالة |
| `.مجموع()` | مجموع العناصر الرقمية |
| `.فريد()` | بلا تكرار |
| `.سطّح()` | يفرد مستوى واحداً من القوائم المتداخلة |
| `.اول()` · `.اخر()` | أول / آخر عنصر |
| `.ابحث(x)` | فهرس أول ورود أو `-1` |
| `.يحتوي(x)` | هل العنصر موجود |
| `.جزء(من, الى؟)` | قائمة جزئية (مثل النصوص) |
| `.انسخ()` | نسخة سطحية |
| `.امسح()` | يفرغ القائمة |

دوال `حول` و`رشح` و`جد` و`اي` و`كل` و`نفذ` تستدعي الدالة بعنصر واحد.

### 4.7) طرق القواميس

| الطريقة | الوظيفة |
|---|---|
| `.طول` | عدد المفاتيح |
| `.مفاتيح()` · `.قيم()` · `.ازواج()` | قوائم المفاتيح / القيم / أزواج `[مفتاح، قيمة]` (بترتيب الإدخال) |

| الدالة | الوظيفة |

### ضخم (أعداد صحيحة بلا حد)

تُمرَّر الأعداد **نصوصاً** وتعيد نصوصاً، فلا تفقد دقة: `ضخم.جمع("99999999999999999999", "1")` ← `"100000000000000000000"`.

| الدالة | الوظيفة |
|---|---|
| `جمع(أ, ب)` · `طرح(أ, ب)` · `ضرب(أ, ب)` | العمليات الأساسية |

| `قوة(نص, رقم)` | الأس: `ضخم.قوة("2", 100)` (الأس رقم عادي) |
| `مضروب(ن)` | `ن!` (`مضروب(25)`) |
| `قارن(أ, ب)` | `1` إن أ>ب و`0` متساويان و`-1` إن أ<ب |
| `رقم(نص)` | يتحقق من النص ويعيده بصيغته المعيارية (`"0042"` ← `"42"`) |

| `فك(نص)` | نص JSON ← قيمة سولان (`null` ← `عدم`) |

### نمط (التعابير النمطية)

محرك مدمج يدعم المجموعات والمجموعات المسمّاة و`\d \w \s` والحدود والنظرات الأمامية، وبلا مكتبة خارجية. كل دالة تأخذ `(نمط, نص, خيارات؟)`.

| الدالة | الوظيفة |
|---|---|
| `ابحث(نمط, نص)` | أول تطابق: قاموس `{نص، بداية، نهاية، مجموعات، مسميات}` أو `عدم`. `مجموعات` قائمة نصوص المجموعات، و`مسميات` قاموس المجموعات المسمّاة `(?<اسم>...)` |
| `هل(نمط, نص)` | هل يوجد تطابق في أي موضع |
| `مطابق_كامل(نمط, نص)` | هل يطابق النص **كله** |
| `كل(نمط, نص)` | قائمة بكل التطابقات (كل عنصر قاموس مثل نتيجة `ابحث`) |
| `قسم(نمط, نص)` | يقسم النص عند التطابقات |
| `ابدل(نمط, نص, بديل, خيارات؟)` | استبدال (يدعم `$1` `$2` للمجموعات) |

الخيارات قاموس: `{"تجاهل_الحالة": صح}` و`"تطبيع"` (يتجاهل الهمزات والتشكيل) و`"متعدد"` (`^`/`$` لكل سطر) و`"نقطة_سطر"` (النقطة تطابق السطر الجديد). مثال: `نمط.هل("HELLO", "hello", {"تجاهل_الحالة": صح})` ← `صح`.

```
استورد "نمط"
خل م = نمط.ابحث("(\\d+)-(\\d+)", "هاتف 555-1234")
اطبع(م.نص)                                         // 555-1234
اطبع(نمط.ابدل("(\\w+)@(\\w+)", "ali@site", "$2:$1")) // site:ali
```

(داخل نص سولان يُكتب الشرطة المائلة مضاعفة: `"\\d"`.)

### تشفير

| الدالة | الوظيفة |
|---|---|
| `sha256(نص)` · `sha1(نص)` | بصمة ست عشرية (`sha256("abc")` ← `ba7816bf...15ad`) |
| `hmac_sha256(مفتاح, رسالة)` | توقيع HMAC |
| `base64(نص)` · `فك_base64(نص)` | ترميز وفك Base64 |
| `hex(نص)` · `فك_hex(نص)` | ترميز وفك ست عشري |
| `عشوائي_بايتات(ن)` | `ن` بايتات عشوائية آمنة تشفيرياً |

### ضغط

| الدالة | الوظيفة |
|---|---|
| `gzip(نص)` · `gunzip(بيانات)` | ضغط وفك بصيغة gzip |
| `zlib(نص)` · `فك(بيانات)` | ضغط zlib وفك أي من الصيغتين |

الضغط مضمَّن في اللغة ولا يحتاج `libz`.

### شبكة (HTTP)

| الدالة | الوظيفة |
|---|---|
| `جلب(رابط, خيارات؟)` | طلب HTTP/HTTPS متزامن (حاجب). يعيد `{حالة، جسم، رؤوس، ناجح، رابط}` |
| `خادم(منفذ, معالج, خيارات؟)` | خادم HTTP (حاجب) |
| `خادم_حلقة(منفذ, معالج, خيارات؟)` | خادم HTTP على حلقة الأحداث (لا يحجب؛ المعالج قد يكون `غير_متزامن`) |
| `ترميز_رابط(نص)` · `فك_رابط(نص)` | ترميز وفك النص داخل الروابط (%XX) |
| `اقرا_طلب(...)` · `اكتب_رد(...)` | مستوى منخفض لبناء خوادم مخصصة فوق السوكت |

**خيارات `جلب`:** `طريقة` (`"GET"` افتراضياً)، `رؤوس` (قاموس)، `جسم` (نص، أو قاموس/قائمة فيُرسَل JSON تلقائياً)، `مهلة` (ثواني)، `تحقق` (`غلط` يعطّل فحص شهادة TLS)، `تحويلات` (عدد التحويلات المسموحة)، `نموذج` (قاموس لإرسال `multipart/form-data`)، `نموذج_رابط` (قاموس بصيغة `x-www-form-urlencoded`).

**معالج الخادم** يستقبل `طلب` بالحقول: `طريقة` `مسار` `استعلام` (قاموس) `رؤوس` `جسم` `عنوان` (عنوان العميل). وما يعيده يتحدد هكذا:

- نص ← استجابة HTML.
- قاموس فيه `جسم` و`حالة` و`رؤوس` (كلها اختيارية): `حالة` رمز HTTP (200 افتراضياً)، و`جسم` نص أو قاموس/قائمة (فيُرسَل JSON).

**خيارات `خادم`:** `عنوان` (للاستماع)، `اقصى_طلبات`، `عمليات` (عدد العمليات العاملة)، و`شهادة` + `مفتاح` لتشغيل HTTPS.

### حلقة (حلقة الأحداث)

| الدالة | الوظيفة |

| `الغ_مراقبة(مقبض)` | يوقف المراقبة |
| `خطوة()` | دورة واحدة من الحلقة |
| `شغل()` | يشغّل الحلقة حتى لا يبقى عمل أو يُستدعى `اوقف` |


### قاعدة (SQLite)

| الدالة | الوظيفة |
|---|---|
| `افتح(مسار)` | يفتح ملف قاعدة (ينشئه إن لم يوجد) ويعيد مقبضاً |
| `نفذ(قاعدة, استعلام, معاملات؟)` | ينفّذ أمراً (INSERT/UPDATE/CREATE...) |
| `استعلم(قاعدة, استعلام, معاملات؟)` | ينفّذ SELECT ويعيد **قائمة قواميس** بأسماء الأعمدة |
| `اغلق(قاعدة)` | يغلق القاعدة |

المعاملات توضع في قائمة وتُربط بعلامات `?` (آمن من حقن SQL). مثال:

```
استورد "قاعدة"
خل ق = قاعدة.افتح("t.db")
قاعدة.نفذ(ق, "CREATE TABLE IF NOT EXISTS ت(ا INTEGER, ب TEXT)")
قاعدة.نفذ(ق, "INSERT INTO ت VALUES (?, ?)", [1, "س"])
اطبع(قاعدة.استعلم(ق, "SELECT * FROM ت WHERE ا = ?", [1]))   // [{"ا": 1، "ب": "س"}]
قاعدة.اغلق(ق)
```

إن بُني سولان بـ SQLite مضمَّناً فلا يحتاج مكتبة نظام، وإلا يحمّل `libsqlite3` وقت التشغيل (وإن غابت: `SQLite غير متاح في هذا البناء`).

### ألوان

كل دالة تأخذ نصاً وتعيده ملفوفاً بأكواد ANSI (وتتعطل تلقائياً إن لم تكن المخرجات طرفية أو ضُبط `NO_COLOR`):

| الدالة | الوظيفة |
|---|---|
| `اسود` `احمر` `اخضر` `اصفر` `ازرق` `بنفسجي` `سماوي` `ابيض` `رمادي` `(ن)` | ألوان النص (وللفاتح: `احمر_فاتح` وأخواتها) |
| `خلفية_اسود` `خلفية_احمر` … `(ن)` | ألوان الخلفية |
| `غامق` `خافت` `مائل` `مسطر` `وميض` `معكوس` `مشطوب` `(ن)` | التنسيق |
| `لون(اسم, ن)` · `لون256(رقم, ن)` · `خلفية256(رقم, ن)` · `rgb(ر,غ,ب,ن)` · `خلفية_rgb` · `هيكس("ff8800", ن)` · `خلفية_هيكس` | ألوان مخصصة |
| `ضبط(قيمة)` | يفعّل/يعطّل الألوان يدوياً |
| `وسوم(نص)` | وسوم ملونة: `ألوان.وسوم("[احمر]خطأ[/] عادي")` |
| `ازل(ن)` · `طول_مرئي(ن)` | يحذف أكواد الألوان / الطول الظاهر |
| `اطار(نص, عنوان="", حشو=1)` | يرسم إطاراً حول النص |
| `شريط_تقدم(نسبة, عرض=20, ممتلئ, باقي)` | `شريط_تقدم(0.5, 10)` ← `█████░░░░░ 50%` |

### اختبار (إطار اختبارات لبرامجك ومكتباتك)

```
استورد "اختبار"
اختبار.مجموعة("حساب", دالة() {
  اختبار.اختبر("جمع", دالة() { اختبار.يساوي(1 + 1, 2) })
  اختبار.اختبر("قسمة على صفر", دالة() { اختبار.يرمي(دالة() { خل ز = 1 / 0 }) })
})
اختبار.شغل_الكل()        // يطبع التقرير؛ وإن فشل اختبار ينهي البرنامج برمز 1
```

| الدالة | الوظيفة |
|---|---|
| `مجموعة(اسم, ف)` · `اختبر(اسم, ف)` | تنظيم الاختبارات |
| `ارجئ(اسم, ف)` · `فقط(اسم, ف)` | تخطّي اختبار / تشغيل هذا فقط |
| `قبل_كل(ف)` `بعد_كل(ف)` `قبل_الكل(ف)` `بعد_الكل(ف)` | خطافات |
| `يساوي(فعلي, متوقع)` `لا_يساوي(أ, ب)` `قريب(أ, ب, دقة)` `اكبر_من` `اصغر_من` | تأكيدات المقارنة |
| `هو_صح(ق)` `هو_غلط(ق)` `هو_عدم(ق)` `ليس_عدم(ق)` `تأكد_ان(شرط, رسالة)` | تأكيدات القيم |
| `من_نوع(ق, ن)` `طول_يساوي(ق, ن)` `يحتوي(حاوية, عنصر)` `لا_يحتوي` `يطابق(س, ن)` | تأكيدات الأنواع والمحتوى |
| `يرمي(ف, ن)` · `لا_يرمي(ف)` | تأكيدات الأخطاء |
| `وهمية(ناتج)` · `استدعيت_مرات(م, عدد)` · `استدعيت_بوسائط(م, ...وسائط)` | دوال وهمية (mocks) |
| `شغل_الكل(انهاء=صح, مرشح, تقرير=غلط)` | يشغّل الاختبارات ويطبع التقرير. مع `انهاء=صح` (الافتراضي) ينهي البرنامج برمز `1` عند أي فشل؛ وإن كان `انهاء=غلط` يعيد قاموس النتائج |

### سجل

| الدالة | الوظيفة |
|---|---|
| `جديد(اسم, حقول)` | مسجِّل باسم، بطرق `.تصحيح` `.معلومة` `.تحذير` `.خطأ` `.حرج` و`.مع(حقول)` و`.فرعي(اسم)` |
| `تصحيح(...)` `معلومة(...)` `تحذير(...)` `خطأ(...)` `حرج(...)` | تسجيل عام مباشر |
| `مستوى(م)` | أدنى مستوى يُطبع |
| `ملف(مسار)` · `صيغة(ص)` · `اضف_معالج(ف)` · `امسح_المعالجات()` | المخرج والصيغة ومعالجات مخصصة |

### ذاكرة (ذاكرة مؤقتة)

`ذاكرة.جديد(سعة=0, عمر=0)` تعيد ذاكرة بحد أقصى `سعة` عنصر (الأقدم استعمالاً يُطرد) وعمر افتراضي `عمر` ثانية (0 = بلا حد). أعضاؤها: `.ضع(مفتاح, قيمة, عمر)` `.خذ(مفتاح, افتراضي)` `.يوجد` `.احذف` `.امسح` `.نظف` `.حجم` `.مفاتيح` `.احسب(مفتاح, ف, عمر)` (يحسب القيمة بالدالة مرة واحدة ثم يخزنها) `.احصائيات()`. و`ذاكرة.احفظ_نتيجة(ف, عمر, سعة)` تعيد دالة تخزّن نتائج `ف` تلقائياً.

### بث (مرسل أحداث)

```
استورد "بث"
خل ب = بث.جديد()
ب.على("رسالة", دالة(نص) { اطبع("وصلت:", نص) })
ب.ارسل("رسالة", "أهلا")     // وصلت: أهلا
```

الأعضاء: `.على(حدث, ف)` `.مرة(حدث, ف)` (مرة واحدة) `.الغ(حدث, ف)` `.امسح(حدث)` `.ارسل(حدث, ...وسائط)` `.عدد_المستمعين(حدث)` `.اسماء_الاحداث()`.

### عمال (التوازي)

| العنصر | الوظيفة |
|---|---|
| `مجمع_جديد(عدد, معالج)` | مجمع من `عدد` عملية عاملة: `.حول(قائمة)` (وعد بنتائج المعالج على كل عنصر بالتوازي) و`.نفذ(بيانات)` و`.اغلق()` |
| `انشئ(ف)` | عملية عاملة واحدة: `.ارسل(رسالة)` `.استقبل()` `.عند_رسالة(ف)` `.اطلب(رسالة)` (وعد بالرد) |
| `خادم_طلبات(معالج)` | يبني خادم طلبات بعمال |
| `قناة` | قناة اتصال بين العمليات: `.ارسل` `.استقبل` |

```
استورد "عمال"
غير_متزامن دالة رئيسي() {
  خل م = عمال.مجمع_جديد(2, دالة(ن) { ارجع ن * ن })
  اطبع(انتظر م.حول([1, 2, 3]))    // [1، 4، 9]
  م.اغلق()
}
شغل(رئيسي)
```

### وسائط (قراءة سطر الأوامر)

```
استورد "وسائط"
خل نتيجة = وسائط.حلل(["--اسم", "علي", "-v", "ملف"], {"اسم": {"نوع": "نص"}, "v": {"نوع": "منطقي"}})
// {"خيارات": {"اسم": "علي"، "v": صح}، "موضعية": ["ملف"]، "اخطاء": []، "مجهولة": ["-v"]}
```

| الدالة | الوظيفة |
|---|---|
| `حلل(قائمة, مواصفات)` | يحلل القائمة (عادةً `وسائط`) إلى `{خيارات، موضعية، اخطاء، مجهولة}`. المواصفات قاموس: اسم الخيار ← `{نوع، افتراضي، اختصار}` |
| `مساعدة(مواصفات, عنوان)` | نص مساعدة منسّق |
| `حلل_او_اخرج(قائمة, مواصفات, وصف, امر_اسم)` | يحلل ويطبع المساعدة/الأخطاء ويخرج عند الحاجة |
| `حلل_اوامر(قائمة, اوامر, عام)` · `مساعدة_اوامر(...)` | برامج متعددة الأوامر (مثل `git add`) |

## 8) الصلاحيات والأمان

افتراضياً للبرنامج كل الصلاحيات. يمكنك تقييدها على طريقة Deno، بست فئات: `قراءة` `كتابة` `شبكة` `تنفيذ` `بيئة` `اصلي` (والمقصود بـ `اصلي` تحميل المكتبات الأصلية و`ffi`)، ويجمعها `الكل`.

```bash
solan --اسمح-قراءة=/بيانات --اسمح-كتابة=/مخرجات --اسمح-شبكة=api.example.com سكربت.سو
solan --امنع=تنفيذ,شبكة سكربت.سو      # كل شيء مسموح عدا التنفيذ والشبكة
solan --اسمح=قراءة سكربت.سو            # كل ما عدا القراءة ممنوع
solan --آمن سكربت.سو                   # قراءة وبيئة فقط
```

- `--اسمح=فئة,فئة` يمنح الفئات المذكورة **ويمنع كل ما عداها**.
- `--اسمح-قراءة=/مسار1,/مسار2` و`--اسمح-كتابة=...` يحصران الوصول في مجلدات محددة (تُفحص بعد حل الروابط الرمزية و`..`).
- `--اسمح-شبكة=مضيف1,مضيف2` يحصر الشبكة في مضيفين (يطابق المضيف تماماً أو نطاقاً فرعياً منه).
- `--امنع=فئة,...` يسحب الفئات المذكورة.
- المكافئات الإنجليزية: `--allow` و`--allow-read=` و`--allow-write=` و`--allow-net=` و`--deny` و`--safe`، وأسماء الفئات: `read` `write` `net` `exec` `env` `native` `all`.
- فئة غير معروفة تعطي `صلاحية غير معروفة: ...` ورمز خروج `64`.

عند المخالفة يُرمى خطأ يمكن مسكه:

```
خطأ: الصلاحية غير ممنوحة لهذا المسار: كتابة (/tmp/x.txt)
خطأ: الصلاحية غير ممنوحة: تنفيذ (شغّل بـ --اسمح=تنفيذ)
خطأ: الصلاحية غير ممنوحة: شبكة (المضيف 127.0.0.1)
```

متغير البيئة `SOLAN_SAFE=1` يفعّل الوضع الآمن بلا خيارات. وبهذه الصلاحيات يمكنك تشغيل شيفرة غير موثوقة بحذر، لكنها ليست صندوق رمل كاملاً؛ للتبليغ عن الثغرات انظر `SECURITY.md`.

## 9) المكتبات والحزم: استعمالها وتنزيلها

المكتبات في سولان **مستودعات git عادية**: لا خادم مركزي ولا خطوة بناء. المكتبة تُخزَّن مرة واحدة في مجلد المستخدم (`~/.solan/store`) وتُشارَك بين كل المشاريع. المشروع يضم ملفين فقط: `solan.json` (ما تريده) و`solan.lock` (ما حصلتَ عليه بالضبط). لا يوجد مجلد مكتبات داخل المشروع. يلزم `git` عند التثبيت فقط.

### البدء: مشروع يستعمل مكتبة

```bash
mkdir مشروعي && cd مشروعي
solan init                                   # ينشئ solan.json
solan add owner/مساعد_نصوص                   # من GitHub: يختار أعلى إصدار ويثبّته
solan add https://gitlab.com/a/b.git          # من أي مستودع git (https و ssh و file)
solan add اسمي=owner/repo@^1.2.0              # باسم استيراد مخصص ونطاق إصدار
solan add ./libs/محلي                         # مكتبة محلية أثناء التطوير
```

ثم في الكود:

```
استورد "مساعد_نصوص"
اطبع(مساعد_نصوص.مرحبا("عالم"))
```

وإن تغيّر المشروع على جهاز آخر: `solan install` يثبّت ما في `solan.json` ويلتزم بالقفل.

### solan.json (المشروع)

```json
{
  "الاسم": "بوتي",
  "النسخة": "0.1.0",
  "الاعتماديات": {
    "ادوات": "mylang/tools@^1.2.0",
    "مساعد": "git+https://gitlab.com/a/b.git@~2.1.0",
    "تجريبي": "owner/repo#main",
    "محلي": "./libs/محلي"
  }
}
```

- مفتاح الاعتمادية هو **اسم الاستيراد** ويجوز أن يكون عربياً: `استورد "ادوات"`.
- المصدر: `owner/repo[@نطاق]` (GitHub)، أو رابط git كامل (`https://` و`ssh://` و`git@host:path` و`file://`)، أو `#فرع` أو `#التزام`، أو مسار محلي (للتطوير؛ يُربط ولا يُنسخ؛ للمشروع الرئيسي فقط).
- نطاقات الإصدار: `1.2.3` و`^1.2.3` و`~1.2.3` و`>=1.0.0 <2.0.0` و`1.x` و`*` و`latest`. لا يجوز الجمع بين نطاق و`#`.
- الإصدارات هي وسوم git بالشكل `vX.Y.Z`؛ وسوم ما قبل الإصدار تُتجاهل.
- يُقبل أيضاً الأسماء الإنجليزية للمفاتيح: `name` و`version` و`dependencies` و`entry` (لكن لا يجوز المفتاحان العربي والإنجليزي معاً للاعتماديات).

### أوامر الحزم

| الأمر | الوظيفة |
|---|---|
| `solan init [--lib]` | ينشئ `solan.json` (ومع `--lib` هيكلة مكتبة كاملة) |
| `solan add [اسم=]مصدر[@نطاق]` | يضيف ويثبّت (بلا نطاق يكتب `^` لآخر وسم). `--as اسم` بديل لـ `اسم=`. عند فشل التثبيت يُعاد `solan.json` كما كان |
| `solan install` | يثبّت ما في `solan.json` ويحترم القفل. `--local` يفضّل المتجر المحلي دون شبكة، و`--quiet` |
| `solan install --frozen` | القفل فقط بلا ترقية، يتحقق من البصمات ويعيد جلب أي حزمة معدَّلة (للـCI) |
| `solan remove اسم...` | يحذف اعتماديات (المتجر المشترك يبقى) |
| `solan update [اسم] [--major]` | يرقّي ضمن النطاق، و`--major` يغيّر النطاق للإصدار الرئيسي الأحدث |
| `solan list [--tree] [--store]` | الاعتماديات (والمتداخلة مع `--tree`)، أو محتوى المتجر كله |
| `solan outdated` | الحالي والمسموح والأحدث لكل اعتمادية |
| `solan why اسم` | من يطلب هذه الحزمة ولماذا هي مثبتة |
| `solan verify` | يقارن بصمات المتجر بالقفل |
| `solan prune [--dry-run]` | يحذف من المتجر ما لا يستعمله أي مشروع مسجَّل |
| `solan cache clean` | يمسح التنزيلات المؤقتة |
| `solan publish [--dry-run] [--push]` | يفحص المكتبة وينشئ الوسم `vX.Y.Z` (ويدفعه مع `--push`) (انظر القسم 10) |

الأسماء العربية مقبولة أيضاً: `ثبت` `اضف` `ازل` `قائمة` `حدث` `تحقق` `قديمة` `لماذا` `تنظيف` `كاش` `انشر` `بدء`. تُشغَّل الأوامر من أي مجلد فرعي داخل المشروع (يُكتشف `solan.json` صعوداً). خارج أي مشروع تعمل `install مصدر` و`remove` و`list` على المكتبات العامة القديمة (`~/.solan/modules`)، و`--global` يفرض ذلك داخل مشروع.

### ما يحدث عند التثبيت وعند التشغيل

1. `solan add` يقرأ وسوم المستودع (`git ls-remote --tags`) ويختار أعلى إصدار يحقق النطاق.
2. يجلب `git clone --depth 1` إلى مجلد مؤقت، يتحقق من الروابط الرمزية والحجم، يحسب بصمة sha256 لشجرة الملفات، ثم ينقله ذرياً إلى `~/.solan/store/<المضيف>/<owner>/<repo>/<الإصدار>/`.
3. يكتب `solan.lock` فيه الالتزام (commit) والبصمة لكل حزمة (المباشرة والمتداخلة).
4. عند تشغيل برنامجك يقرأ المحرك القفل ويصل مباشرة لمسار الحزمة في المتجر (بلا شبكة ولا كتابة في المشروع).
5. إن غاب القفل أو تغيّر `solan.json` أو فُقدت حزمة: تثبيت تلقائي لمرة واحدة (يفضّل المتجر المحلي) ثم يكمل التشغيل. لا يعمل التثبيت التلقائي مع `--امنع=شبكة` أو `--امنع=تنفيذ`.

**ترتيب حلّ الاسم** في `استورد "x"`: مسار نسبي ← مكتبة مدمجة/قياسية (لا تُغطّى أبداً) ← اعتماديات الحزمة/المشروع من القفل ← المسارات القديمة. كل حزمة تحلّ اعتمادياتها من قفلها الخاص، فلا تتعارض إصدارات مختلفة لحزمتين. ويمكن استيراد ملف فرعي من حزمة: `استورد "ادوات/src/عميل"`.

### أين تُخزَّن المكتبات (مجلد البيت)

يُختار أول مسار قابل للكتابة بالترتيب: (1) `SOLAN_HOME` (صريح؛ إن لم يكن قابلاً للكتابة يظهر خطأ)، (2) على ويندوز `%LOCALAPPDATA%\Solan`، (3) `~/.solan`، (4) `<المشروع>/.solan` عندما يكون البيت للقراءة فقط (حاويات)، (5) `<temp>/solan-<معرّف المستخدم>`.

```text
<البيت>/store/<المضيف>/<owner>/<repo>/<الإصدار>/   الحزم المنزَّلة (دائمة، مشتركة)
<البيت>/cache/                                    تنزيلات مؤقتة (solan cache clean)
<البيت>/projects.json                             قائمة المشاريع لأمر prune
```

### الاختلافات بين الأنظمة

| الموضوع | السلوك |
|---|---|
| فاصل المسارات | داخلياً `/` دائماً (تُحوَّل مسارات ويندوز) |
| حالة الأحرف | معرّفات GitHub/GitLab/Bitbucket/Codeberg تُحوَّل لأحرف صغيرة (`Owner/Repo` = `owner/repo`) |
| نهايات الأسطر | تُجلب دائماً بـ LF (`core.autocrlf=false`) فتتطابق البصمة على كل الأنظمة |
| الشبكة | بلا مطالبات (`GIT_TERMINAL_PROMPT=0`)، وقطع الاتصال البطيء بعد 30 ثانية، ومهلة اتصال ssh 20 ثانية |
| ويندوز: المسارات الطويلة | الحد الافتراضي 260 حرفاً: فعّل «Long Paths» أو اجعل `SOLAN_HOME` قصيراً (مثل `C:\so`) |

### الأمان والقيود

| القيد | القيمة |
|---|---|
| سكربتات التثبيت | لا يُنفَّذ أي كود من المكتبة وقت التثبيت أو النشر |
| الروابط الرمزية | ممنوعة داخل المكتبة (تُرفض عند التثبيت والنشر) |
| عدد الملفات / الحجم | 5000 ملف / 50 ميغابايت كحد أقصى |
| عمق الاعتماديات / عددها | 16 مستوى / 500 حزمة |
| البروتوكولات | `https` و`http` و`ssh` و`git` و`file` فقط (`ext::` مرفوض) |
| سلامة الاسترجاع | الالتزام والبصمة في القفل؛ `solan install --frozen` و`solan verify` يكشفان أي تلاعب |
| التوقيع الرقمي | لا يوجد؛ الأمان بالالتزام والبصمة المسجَّلين في القفل |

حدود معروفة: التنزيل متسلسل (حزمة بعد حزمة)، و`solan prune` لا يعرف إلا المشاريع التي ثبّتَّ فيها بهذا الإصدار أو أحدث، والحزم الثنائية الأصلية لا تُختار حسب المنصة.

## 10) كتابة مكتبة ونشرها

المكتبة **مستودع git** فيه ملف `solan.json` وكود `.سو`. النشر = وسم git. جرّبنا هذه الدورة كاملة (إنشاء، نشر، إضافة من مشروع آخر، تحديث، إزالة).

### 10.1) البدء السريع

```bash
mkdir مساعد_نصوص && cd مساعد_نصوص
git init
solan init --lib          # ينشئ الهيكلة (الاسم = اسم المجلد)
solan tests/اختبار.سو     # يشغّل اختبار المكتبة
git add -A && git commit -m "أول نسخة"
solan publish --dry-run   # يفحص كل شيء دون نشر
solan publish --push      # ينشئ الوسم v0.1.0 ويدفعه إلى origin
```

ثم أي شخص يكتب في مشروعه `solan add owner/مساعد_نصوص` ثم `استورد "مساعد_نصوص"`.

### 10.2) هيكل المجلد

```text
مساعد_نصوص/
├── solan.json          بيان المكتبة (إجباري)
├── رئيسي.سو            نقطة الدخول (الاسم الافتراضي)
├── src/                ملفاتك الداخلية (اختياري)
├── tests/اختبار.سو     اختباراتك (اختياري)
├── README.md
└── README.md
```

الإجباري فقط `solan.json` وملف الدخول. لا مجلد بناء ولا ملف قفل داخل المكتبة (القفل للمشاريع لا للمكتبات). القالب الذي ينشئه `solan init --lib` يحتوي دالة `مرحبا(اسم)` واختباراً يشغَّل بـ `solan tests/اختبار.سو`.

### 10.3) solan.json للمكتبة

```json
{
  "الاسم": "مساعد_نصوص",
  "النسخة": "1.0.0",
  "الوصف": "دوال مساعدة صغيرة للنصوص",
  "المؤلف": "اسمك",
  "الرخصة": "MIT",
  "المدخل": "رئيسي.سو",
  "الاعتماديات": {
    "ادوات": "owner/tools@^1.2.0"
  }
}
```

| الحقل (والبديل الإنجليزي) | الوظيفة | يستعمله النظام؟ |
|---|---|---|
| `الاسم` / `name` | اسم المكتبة. إجباري عند `solan publish` | `publish` فقط |
| `النسخة` / `version` | رقم الإصدار `MAJOR.MINOR.PATCH` | نعم: `publish` يتحقق منه وينشئ الوسم، والتثبيت يحذّر إن خالف الوسم |
| `الوصف` · `المؤلف` · `الرخصة` | معلومات للقرّاء | لا |
| `المدخل` / `entry` | ملف الدخول (مسار نسبي داخل المكتبة، دون `..`). الافتراضي `رئيسي.سو` | نعم |
| `الاعتماديات` / `dependencies` | ما تحتاجه مكتبتك | نعم |

### 10.4) الإصدار: أين يوضع وكيف يتغير

الإصدار له مكانان **يجب أن يتطابقا**:

1. **`النسخة` داخل `solan.json`** (مثلاً `1.2.0`) — هذا ما تعرفه اللغة عن مكتبتك.
2. **وسم git بالشكل `v` + النسخة** (مثلاً `v1.2.0`) — هذا ما يقرؤه نظام الحزم لاختيار الإصدار (`git ls-remote --tags`)، فهو الذي ينشر الإصدار فعلاً.

`solan publish` يتولى الاثنين: يتحقق أن `النسخة` صالحة ثم ينشئ الوسم المطابق. خطوات نشر نسخة جديدة:

```bash
# 1) عدّل الكود ثم ارفع "النسخة" في solan.json
git commit -am "إصلاح كذا"        # 2) احفظ
solan publish --push               # 3) انشر (ينشئ الوسم v1.3.0 ويدفعه)
```

**معنى الأرقام (SemVer):**

| ارفع | متى | أثره على المستهلكين |
|---|---|---|
| `PATCH` (1.0.0 ← 1.0.1) | إصلاح خطأ دون تغيير الواجهة | يحصلون عليه بـ `solan update` |
| `MINOR` (1.0.0 ← 1.1.0) | إضافة ميزة متوافقة | يحصلون عليه بـ `solan update` (نطاق `^1.0.0`) |
| `MAJOR` (1.0.0 ← 2.0.0) | تغيير يكسر الواجهة | لا يحصلون عليه إلا بـ `solan update --major` |

انتبه لنطاق `^` مع الإصدارات الصفرية: `^0.4.1` يعني `>=0.4.1 <0.5.0`، و`^0.0.3` يعني `0.0.3` فقط (جرّبنا: مكتبة نُشرت `0.2.0` لم يلتقطها مستهلك على `^0.1.0`). لذلك `0.x` تعني «غير مستقرة»؛ انشر `1.0.0` عندما تثبت واجهتك. وسوم ما قبل الإصدار (`v1.0.0-beta`) وأي وسم ليس `vX.Y.Z` تُتجاهل.

**`publish` يرفض النشر عند أي من:**

- الاسم أو النسخة مفقودة، أو النسخة ليست بالشكل `1.2.3` (يرفض `1.2` و`v1.2.3` و`1.2.3-beta`).
- ملف المدخل غير موجود أو يحوي `..`.
- اعتمادية بمسار محلي (`./...`) أو باسم مكتبة قياسية.
- المجلد ليس مستودع git، أو توجد تغييرات غير ملتزَم بها (`توجد تغييرات غير مُلتزَم بها؛ نفّذ commit أولا`).
- الوسم موجود مسبقاً، أو يوجد وسم **أحدث** من النسخة.
- رابط رمزي، أو أكثر من 5000 ملف، أو حجم فوق 50 ميغابايت.
- اسم ملف لا يصلح على ويندوز/ماك: أحرف ممنوعة (`< > : " | ? * \`)، أو ينتهي بمسافة أو نقطة، أو اسم محجوز (`CON` `NUL` `COM1`...)، أو ملفان يختلفان بحالة الأحرف فقط.

### 10.5) كتابة الكود

**ما الذي يُصدَّر؟** كل ما تعرّفه في المستوى الأعلى من ملف الدخول (دوال ومتغيرات وثوابت وأصناف، وحتى الوحدات التي استوردتها) يصبح عضواً في الوحدة. لا توجد كلمة `export`. للتحكم بالواجهة العامة: ضعها في `رئيسي.سو` كدوال صغيرة تستدعي ملفاتك الداخلية، وابدأ أسماء الأشياء الداخلية بشرطة سفلية `_` (اصطلاح؛ اللغة لا تمنع الوصول إليها).

```
// رئيسي.سو
استورد "./src/حروف"

دالة اعكس(نص) { ارجع حروف.اعكس_نص(نص) }     // واجهة عامة
دالة _مساعدة_داخلية() { ارجع 1 }              // داخلية بالاصطلاح
```

**الاستيراد داخل المكتبة:**

| الشكل | المعنى |
|---|---|
| `استورد "./حروف"` أو `"../x"` | ملف نسبي **إلى الملف الذي يحوي الاستيراد** (وليس إلى مجلد البرنامج الرئيسي) |
| `استورد "ادوات"` | اعتمادية معلنة في `solan.json` الخاص بمكتبتك |
| `استورد "ادوات/src/عميل"` | ملف فرعي داخل الاعتمادية |
| `استورد "نظام"` | مكتبة مدمجة أو قياسية |

الاسم الذي تُربط به الوحدة هو اسم الملف (أو المجلد) دون الامتداد، أو الاسم الذي سمّاه المستهلك في `الاعتماديات`. الوحدة تُحمَّل مرة واحدة وتُخزَّن، والاستيراد الدائري آمن (لا حلقة لا نهائية، لكن الوحدة قد تكون ناقصة التعريف لحظة استيرادها الدائري). تذكّر أن الأسماء تُطبَّع (`قيمة` = `قيمه`)، فلا تعرّف اسمين يختلفان بالهمزات أو التاء فقط.

### 10.6) اختبار المكتبة

اكتب اختبارات في `tests/` تستورد مكتبتك نسبياً وشغّلها `solan tests/اختبار.سو`. استعمل مكتبة `اختبار` (القسم 6)؛ فهي تنهي البرنامج برمز غير صفري عند الفشل، فتصلح للـCI. مجلد `tests/` ينتقل مع المكتبة عند التثبيت لكن لا يستعمله المستهلك.

### 10.7) اعتماديات مكتبتك

تعلنها في `solan.json` بالصيغة نفسها للمشاريع. **كل مكتبة تحلّ اعتمادياتها بنفسها**: لو احتاجت مكتبتان نسختين مختلفتين من `ادوات` تتعايشان بلا تعارض. مفتاح الاعتمادية هو اسم الاستيراد داخل مكتبتك فقط. لا يجوز مسار محلي (`./x`) في مكتبة منشورة.

**الأسماء المحجوزة** (مكتبات مدمجة وقياسية) لا تصلح اسماً لاعتمادية ولا لمكتبتك عند الاستهلاك: `ffi ألوان اختبار بث تشفير تواريخ جداول جيسون حزم حلقة خادم_اللغة ذاكرة رياضيات زمن سجل سوكت شبكة ضخم ضغط عرض عشوائي عمال قاعدة قوالب مجموعات مخطط مسارات ملفات نتيجة نصوص نظام نمط وسائط ويبسوكت`.

### 10.8) مكتبات أصلية (C) داخل الحزم

يمكن لملف الدخول أن يكون وحدة أصلية (`.so` أو `.dylib` أو `.dll`) لأن الاستيراد يتعرف عليها بالامتداد. لكن نظام الحزم **لا يبني ولا يختار ملفاً حسب المنصة**، فتوزيع ملف ثنائي واحد يعمل على منصة واحدة فقط. للتوزيع الواسع اكتب المكتبة بسولان أو وزّع شيفرة C مع تعليمات بناء.

### 10.9) أخطاء شائعة

| الرسالة | السبب | الحل |
|---|---|---|
| الاسم 'x' محجوز للمكتبة القياسية | سمّيت اعتمادية باسم مكتبة مدمجة | `solan add اسم_آخر=owner/x` |
| لا يوجد إصدار يطابق '^2.0.0' | لا وسم `v2.x.x` في المستودع | انشر وسماً أو غيّر النطاق |
| لا يوجد solan.lock صالح | `--frozen` بلا قفل | شغّل `solan install` أولاً وارفع القفل |
| الوسم v1.0.0 موجود مسبقاً | نشرت هذه النسخة | ارفع `النسخة` في `solan.json` |
| يوجد وسم أحدث من النسخة | نسخة أقل من وسم موجود | ارفع النسخة فوق آخر وسم |
| تنبيه: وسم X لا يطابق النسخة المعلنة | وسم `v1.2.0` لكن `النسخة` في الملف شيء آخر | صحّح الملف وانشر نسخة جديدة (لا تعدّل وسماً منشوراً) |
| الحزمة تحتوي رابطاً رمزياً | رابط رمزي في المستودع | احذفه |
| ملفان يختلفان بحالة الأحرف فقط | `Readme.md` و`README.md` | أبقِ واحداً |
| git غير مثبت | git غير موجود في PATH | ثبّت git |

### 10.10) قائمة تحقق قبل النشر

1. `solan tests/اختبار.سو` ينجح.
2. `solan publish --dry-run` ينجح.
3. `النسخة` ارتفعت، والتغييرات محفوظة بـ commit.
4. اختبرتها من مشروع فارغ: `solan add owner/مكتبتي` ثم `استورد` ثم استدعاء.
5. وثّقت الواجهة العامة في `README.md` المكتبة.

## 11) مكتبات أصلية بلغة C وFFI

### 11.1) استدعاء مكتبات C مباشرة (ffi)

```
استورد "ffi"
خل جذر = ffi.ربط(عدم, "sqrt", "d(d)")     // (مكتبة أو عدم، اسم الدالة، التوقيع)
اطبع(جذر(2))                               // 1.4142135623730951
خل ل = ffi.افتح("libm.so.6")
اطبع(ffi.ربط(ل, "cbrt", "d(d)")(27))       // 3
```

التوقيع `نوع_الإرجاع(الوسائط)`، والأنواع: `i` (int32) · `l` (int64) · `p` (مؤشر) · `d` (double) · `s` (نص) · `b` (منطقي) · `v` (void). أمثلة: `"d(d)"` و`"i(ss)"` و`"s(s)"` و`"v()"`. وللذاكرة: `ffi.ذاكرة(حجم)` و`ffi.حرر(مؤشر)` و`ffi.اقرأ_نص(مؤشر, طول؟)` و`ffi.اكتب_نص(مؤشر, نص)`.

**القيود:** x86-64 وAArch64 فقط، وحتى 6 وسائط صحيحة و8 عشرية، ولا `float`، ولا دوال متغيرة الوسائط (`printf`)، ولا استدعاءات راجعة (callbacks). تتطلب صلاحية `اصلي`، وهي أداة غير آمنة بطبيعتها.

### 11.2) كتابة وحدة أصلية (.so)

الواجهة في `include/solan.h`. وحدة صغيرة `hello_native.c`:

```c
#include "solan.h"
#include <stdio.h>

static int add(int argc, const SolanValue *argv, SolanValue *res, void *user) {
  (void)user; (void)argc;
  if (!solan_is_number(argv[0]) || !solan_is_number(argv[1])) return solan_throw("جمع: يتطلب رقمين");
  *res = solan_number(solan_to_number(argv[0]) + solan_to_number(argv[1])); return 0;
}
static int squares(int argc, const SolanValue *argv, SolanValue *res, void *user) {
  (void)user; (void)argc;
  SolanValue l = solan_list_new(); int n = (int)solan_to_number(argv[0]);
  for (int i = 1; i <= n; i++) solan_list_push(l, solan_number((double)i * i));
  *res = l; return 0;
}
int solan_module_init(SolanModule *m) {
  solan_module_add_function(m, "جمع", add, 2, 2, NULL);        // (وحدة، اسم، دالة، أدنى وسائط، أقصى وسائط، بيانات مستخدم)
  solan_module_add_function(m, "مربعات", squares, 1, 1, NULL);
  solan_module_add_value(m, "الاصدار", solan_number(1));
  return 0;
}
```

```bash
cc -O2 -fPIC -shared -I include -o hello.so hello_native.c      # في مجلد المستودع
```

```
استورد "./hello.so"                 // الوحدة تُربط باسم الملف: hello
اطبع(hello.جمع(2, 3))               // 5
اطبع(hello.مربعات(4))                // [1، 4، 9، 16]
اطبع(hello.الاصدار)                  // 1
```

**ملاحظات:** ملف `solan` التنفيذي يصدّر دوال `solan_*` (علم `-rdynamic` عند البناء) لتجدها الوحدة وقت التحميل، فلا تربط وحدتك بـ `libsolan` ولا بالملف التنفيذي. تتطلب صلاحية `اصلي`. الدوال الرئيسية: الإنشاء (`solan_nil` `solan_bool` `solan_number` `solan_string` `solan_list_new` `solan_map_new`)، والفحص (`solan_is_*`)، والتحويل (`solan_to_bool` `solan_to_number` `solan_to_cstr`)، والقوائم (`solan_list_len/get/push`)، والقواميس (`solan_map_set/get`)، ورمي الأخطاء (`solan_throw`)، وتثبيت القيم من جامع المهملات (`solan_pin` `solan_unpin`).

### 11.3) تضمين سولان داخل برنامج C

ابنِ مكتبة مشتركة:

```bash
cc -O2 -fPIC -shared -DSOLAN_LIBRARY -Wno-format-truncation -o libsolan.so solan.c -lm -ldl
```

ثم:

```c
#include "solan.h"
#include <stdio.h>
static int twice(int argc, const SolanValue *argv, SolanValue *res, void *user) {
  (void)argc; (void)user; *res = solan_number(2 * solan_to_number(argv[0])); return 0;
}
int main(void) {
  solan_init();
  solan_register_function("ضعف", twice, 1, 1, NULL);           // دالة عامة في سولان
  if (solan_eval("دالة مربع(س) { ارجع س * س }\nخل نتيجة = ضعف(21)", "demo")) {
    fprintf(stderr, "خطأ: %s\n", solan_last_error()); return 1;
  }
  SolanValue arg = solan_number(12), out;
  if (solan_call("مربع", 1, &arg, &out)) { fprintf(stderr, "خطأ: %s\n", solan_last_error()); return 1; }
  printf("مربع(12) = %g\n", solan_to_number(out));                // مربع(12) = 144
  return 0;
}
```

```bash
cc -I include -o demo demo.c -L. -lsolan -Wl,-rpath,.
```

وبقية الواجهة: `solan_abi_version()` و`solan_eval_file(path)`.

## 12) أدوات المحرر والتنسيق

- **التلوين في الطرفية:** `solan --لون ملف.سو`. وكصفحة HTML: `solan --html ملف.سو > out.html`.
- **المنسّق:** `solan fmt ملف.سو -w` (إزاحة وفراغات)، و`solan fmt ملف.سو --قياسي -w` (مرادفات الكلمات المفتاحية إلى القياسية).
- **فحص الصياغة:** `solan --check ملف.سو`.
- **المصحّح:** `solan --تصحيح ملف.سو` للتنفيذ خطوة بخطوة، و`--نقطة N` لنقطة توقف.
- **خادم اللغة (LSP):** `solan lsp` يعمل عبر stdio ويعطي أي محرر يدعم LSP إكمالاً وتشخيصاً (أخطاء صياغة).
- **إضافة VS Code:** مجلد `editor/vscode/` يحتوي تلويناً وقصاصات وأقواساً تلقائية (تعليقات `//` و`/* */`) وعميل LSP يشغّل `solan lsp`. التثبيت: انسخ المجلد إلى `~/.vscode/extensions/solan-lang`، ثم شغّل `npm install` داخله (يلزم `vscode-languageclient`)، وأعد تشغيل VS Code. يُفعَّل تلقائياً لملفات `.سو` و`.an` و`.solan`. الإعداد `solan.path` يحدد مسار الملف التنفيذي إن لم يكن في `PATH`. ملاحظة صادقة: لم تُختبَر الإضافة داخل VS Code نفسه في بيئة التطوير.

## 13) البناء من المصدر والتطوير على اللغة نفسها

### البناء

```bash
sh install.sh --build-only      # يبني ./solan بلا تثبيت (انظر القسم 1 لكل الخيارات)
```

يبني السكربت مباشرة بالمترجم ما يعادل:

```bash
cc -O2 -Wno-format-truncation -DSOLAN_SQLITE_EMBED -o solan solan.c third_party/sqlite/sqlite3.o -rdynamic -lm -ldl
```

أعلام الربط تتغير حسب المنصة (Linux/Android: `-rdynamic -lm -ldl`، macOS: `-Wl,-export_dynamic -lm`، BSD: `-rdynamic -lm`، Windows: `-lm -lws2_32 -lshell32 -ladvapi32`). علم التصدير **لازم**؛ بدونه تفشل الوحدات الأصلية بخطأ `undefined symbol: solan_*`. أعلام الترجمة الاختيارية عبر `CFLAGS`:

| العلم | الأثر |
|---|---|
| `-DSOLAN_JIT=0` | بلا المجمّع الفوري (الجيت يعمل افتراضياً على x86-64 Linux فقط) |
| `-DSOLAN_FORK=0` | بلا `fork` |
| `-DSOLAN_NOPOOL` | بلا مجمّع الكائنات |
| `-DSOLAN_SQLITE_EMBED` | تضمين SQLite (يضيفه `install.sh` تلقائياً إن وُجد `sqlite3.c`) |
| `-DSOLAN_LIBRARY` | يبني مكتبة مشتركة بدل ملف تنفيذي (القسم 11.3) |

### بنية المصدر

`solan.c` هو نقطة الدخول الوحيدة، ويضم بقية الملفات (`.inc`) في ترجمة واحدة:

| المجلد | المحتوى |
|---|---|
| `src/compiler/` | المحلل المعجمي والمترجم إلى بايتكود، والمفكك، وتلوين الكود |
| `src/vm/` | الآلة الافتراضية وطرق الأنواع (`methods.inc`) والوحدات (`modules.inc`) |
| `src/jit/` | المجمّع الفوري لـ x86-64 |
| `src/core/` | الأنواع وجامع المهملات والذاكرة |
| `src/lib/` | المكتبات الأصلية (ملفات، شبكة، JSON، regex، ضغط، SQLite، TLS، ffi، حزم، وقت، ضخم) |
| `src/runtime/` | نقطة التشغيل `main.inc` والـREPL وأدوات `fmt` و`lsp` وتهيئة الدوال المدمجة (`init.inc`) |
| `src/abi/` | واجهة C (`capi.inc`) و`include/solan.h` |
| `src/platform/` | الفروق بين الأنظمة (POSIX وويندوز) |
| `stdlib/` | المكتبات القياسية المكتوبة بسولان |
| `tools/` | أدوات مساعدة اختيارية |
| `editor/vscode/` | إضافة VS Code |

### إضافة دالة أصلية جديدة

الدوال الأصلية تُعرَّف بالماكرو `NAT(اسم)` وتُسجَّل في `init_natives` (في `src/lib/regex.inc`): `defnat(g, "اسم", fn, أدنى, أقصى)` للدوال العامة، و`MF(m, "اسم", fn, أدنى, أقصى)` لدوال وحدة. المرادفات تُضاف في الجدول `ALIASES` في الملف نفسه (وهو يغذي أيضاً `solan fmt --قياسي`). وطرق النصوص والقوائم والقواميس في `src/vm/methods.inc`.

### تعديل مكتبة قياسية

عدّل الملف في `stdlib/` ثم أعد توليد النسخة المضمَّنة وابنِ من جديد:

```bash
sh install.sh --build-only
```

## 14) الاستقلالية والأداء والحدود المعروفة

### ما الذي يحتاجه الملف التنفيذي فعلاً؟

الهدف: **ملف واحد يعمل بلا تثبيت شيء**.

| الميزة | المصدر | تحتاج شيئاً من النظام؟ |
|---|---|---|
| اللغة نفسها، VM، الجيت، جامع المهملات | داخل المشروع | لا (libc / libm فقط، ومعها libdl على Linux) |
| الضغط (gzip/zlib/deflate) وفك ردود HTTP المضغوطة | داخل المشروع (`flate.inc`) | لا |
| SQLite (مكتبة `قاعدة`) | يُضمَّن من `sqlite3.c` وقت البناء | لا إن ضُمِّن، وإلا يُحمَّل `libsqlite3` من النظام |
| JSON، regex، BigInt، HTTP، WebSocket، المؤقتات | داخل المشروع | لا |
| **TLS** (https وwss وخادم TLS) | يحمّل **OpenSSL** بـ `dlopen` | **نعم**؛ بدونه تعمل الشبكة العادية (http/tcp) فقط |
| FFI والوحدات الأصلية | `dlopen` بطبيعتها | تعتمد على ما تحمّله أنت |

- **الضغط:** DEFLATE وzlib وgzip كاملة مع التحقق من CRC32 وAdler32 والطول، ودعم gzip متعدد الأعضاء، وسقف 512 ميغابايت للمخرجات ضد قنابل الضغط. حجم المخرجات قريب من zlib المستوى 6. الفك أبطأ من libz المُحسَّنة يدوياً، وكافٍ للاستعمال العادي.
- **SQLite:** يُبنى بـ `SQLITE_THREADSAFE=0` (سولان أحادي الخيوط) و`SQLITE_OMIT_LOAD_EXTENSION` (لا تحميل ملحقات أصلية من SQL). التضمين يزيد الملف نحو 1 ميغابايت. يُضمَّن SQLite اختياريًا عند وضع `sqlite3.c` في `third_party/sqlite/` قبل البناء، وإلا تُستخدم مكتبة النظام وقت التشغيل.
- **TLS:** يُبحث عن OpenSSL بالترتيب: `SOLAN_LIBSSL` الصريح، ثم مسارات Linux وAlpine وFreeBSD وmacOS. تُطبع تلميحات التثبيت عند الفشل.
- **التحقق بنفسك:** `solan -e 'اطبع(نظام.منصة())'` يعرض `ضغط_مضمن` و`sqlite_مضمن`، و`ldd ./solan` على Linux يريك المكتبات المربوطة.
- لن يكون الملف ثابتاً بالكامل (`-static`) ما دمت تريد FFI والوحدات الأصلية وTLS، لأنها تعتمد على `dlopen`.

### الأداء

الأداء يتفاوت حسب الجهاز وطبيعة البرنامج. الجيت يغطي الدوال العددية على x86-64 Linux، ولا يغطي الكائنات والدوال المجرّدة.

### الحدود المعروفة

- **المنصات:** Linux وWindows وmacOS وBSD وAlpine وAndroid، مع اختلاف تفاصيل الربط حسب النظام.
- **اللغة:**
  - الأرقام عشرية مزدوجة (دقة الأعداد الصحيحة حتى 2^53؛ للأكبر استعمل `ضخم`).
  - التفكيك لا يدعم الباقي `...` (استعمله في المعاملات والقوائم والقواميس).
  - `نسق` لا يدعم فواصل الآلاف `{:,}` (استعمل `عرض.ارقام_مفصولة`).
  - لا نصوص بثلاث علامات اقتباس؛ النص العادي يمتد عبر الأسطر.
  - لا توجد كلمة `export`: كل تعريفات المستوى الأعلى عامة.
- **الحزم:** التنزيل متسلسل، ولا توقيع رقمي (الأمان بالقفل والبصمة)، والحزم الثنائية لا تُختار حسب المنصة.
- **السوكت:** القراءات الحاجبة (`سطر` و`استقبل`) توقف البرنامج؛ للخوادم استعمل `حلقة.راقب` أو `شبكة.خادم_حلقة`.
